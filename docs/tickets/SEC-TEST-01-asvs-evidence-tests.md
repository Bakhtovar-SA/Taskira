# SEC-TEST-01 — автотесты как доказательства для строк ASVS, где защита есть только в коде

**Статус: открыт.** **Severity: low.** Найдено в SEC-ASVS-01 (самопроверка ASVS 5.0 L2, 2026-10-06; [docs/security/ASVS-L2.md](../security/ASVS-L2.md)).

- **Требования:** ASVS 5.0: V1.1.1, V1.2.4, V1.2.6, V2.3.3, V7.4.2 (и пересмотр V13.4.2 после SEC-CFG-01).
- **Факт:**
  - Защита реализована, но проверяется только чтением кода: экранирование LDAP-фильтра и DN (`services/ldap.ts:70,76`), отсутствие конкатенации SQL, отказ сессии JWT после деактивации (`routes/users.ts:116-120` — тест есть только для API-токенов), двойное декодирование входных данных.
  - Атомарность бизнес-операций (V2.3.3): откат под тестом только у создания задачи по расписанию (`server/test/recurring.test.ts:185-192`); `server/test/workflow.transaction.test.ts` — один тест с замоканным `withTransaction`, атомарность не проверяет. Для правки пользователей, создания проекта из шаблона, рангов и завершения спринта автотеста отката нет.
  - Известные пароли по умолчанию (`KNOWN_DEFAULTS`, `passwordPolicy.ts:3-12`) отдельно не изолированы тестом: `config.security.test.ts` подаёт `admin`, который отвергается уже по длине.
- **Почему важно:** без теста регрессия не будет замечена, а аудитор потребует воспроизводимое доказательство.
- **Что сделать:**
  1. Юнит-тест `escFilter`/`escDn` на `*`, `(`, `)`, `\`, NUL, `,`, `+`, ведущий `#` (экспортировать функции или тестировать через `ldapAuthenticate` с моком).
  2. Интеграционный тест: деактивированный пользователь с действующим JWT/кукой получает 401 на следующем запросе; смена роли завершает сессию.
  3. Тесты путей с кодированием (`%2e%2e`, двойное `%25`) для `:id`/`:projectId` и имён вложений; тест-страж, который сканирует `server/src` на SQL-шаблоны с интерполяцией и сверяет их с белым списком известных безопасных мест.
  4. Интеграционные тесты отката: ошибка на середине правки пользователя, создания проекта из шаблона и завершения спринта оставляет БД в прежнем состоянии.
- **Критерий готовности:** тесты в CI; соответствующие строки в ASVS-L2.md ссылаются на них, пометка «без теста» снята.
- **Не сделано:** ничего из перечисленного.
