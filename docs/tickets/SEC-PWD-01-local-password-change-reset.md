# SEC-PWD-01 — локальные пользователи не могут сменить пароль, сброса пароля нет

**Статус: открыт.** **Severity: high.** Найдено в SEC-ASVS-01 (самопроверка ASVS 5.0 L2, 2026-10-06; [docs/security/ASVS-L2.md](../security/ASVS-L2.md)).

- **Требования:** ASVS 5.0: V6.2.2, V6.2.3, V6.4.1, V6.4.3, V7.4.3 (и условие применимости V7.5.1).
- **Факт:**
  - в `server/src/routes` нет маршрута смены или сброса пароля; `password_hash` пишется только в `POST /admin/users` (`routes/users.ts:61-66`) и в сидере (`seed.ts:27`).
  - Пароль локальной учётки задаёт администратор и знает его; пользователь заменить его не может, забытый пароль восстановить нельзя (`PATCH /users/:id` меняет только `globalRole`/`isActive`). Затронуты режим `AUTH_MODE=local` и break-glass администратор в LDAP-режиме (его пароль меняется только правкой `.env` и пересозданием БД-строки).
  - Начальный пароль не генерируется, не истекает и остаётся постоянным.
- **Почему важно:** для клиентов без LDAP это основной режим; покупатель (и аудитор по ASVS 6.2.2/6.4.3) спросит об этом первым, а компрометация одного пароля необратима без вмешательства в БД.
- **Решение:** чинить до внешнего аудита — high, основной режим клиентов без LDAP; реализуется отдельной веткой.
- **Что сделать:**
  1. `POST /api/me/password` (только `requireSession`, не токен): текущий и новый пароль (V6.2.3), политика из `passwordPolicy.ts`, после смены `session_version + 1` и отзыв остальных сессий (V7.4.3), запись в аудит, лимит запросов.
  2. Административный сброс: `POST /api/admin/users/:id/password-reset` — генерирует одноразовый временный пароль (CSPRNG), помечает `must_change_password`, срок жизни, показывает один раз с `Cache-Control: no-store`; вход с таким паролем разрешает только смену пароля (V6.4.1).
  3. Клиент: форма в личных настройках и принудительная смена при первом входе.
  4. ADR (новая аутентификационная функция) и обновление `docs/SECURITY_OVERVIEW.md`.
- **Критерий готовности:** тесты: смена с неверным текущим паролем — 401/403; после смены старый JWT не работает; временный пароль годится только для смены; временный пароль нельзя использовать повторно после смены. Строки V6.2.2, V6.2.3, V6.4.1, V6.4.3, V7.4.3 в `docs/security/ASVS-L2.md` пересмотрены.
- **Не сделано:** ничего из перечисленного.
