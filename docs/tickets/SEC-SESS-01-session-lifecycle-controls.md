# SEC-SESS-01 — жизненный цикл сессий: нет тайм-аута неактивности, списка и завершения сессий

**Статус: открыт.** **Severity: medium.** Найдено в SEC-ASVS-01 (самопроверка ASVS 5.0 L2, 2026-10-06; [docs/security/ASVS-L2.md](../security/ASVS-L2.md)).

- **Требования:** ASVS 5.0: V7.1.1, V7.1.2, V7.2.4, V7.3.1, V7.4.5, V7.5.2, V3.3.4 (+ токен в теле ответа входа, V14.3.3).
- **Факт:**
  - Только абсолютный срок 8 ч; ротация куки не сокращает срок (`middleware.ts:228-254`, тест `auth.cookie.test.ts:72-93`), тайм-аута неактивности нет (V7.3.1) и он не документирован (V7.1.1).
  - Таблицы сессий нет: число параллельных сессий не определено (V7.1.2), пользователь не видит и не завершает свои сессии (V7.5.2), администратор завершает сессии только деактивацией или сменой роли (V7.4.5).
  - Повторный вход не отзывает предыдущие токены пользователя (V7.2.4).
  - `POST /auth/login` возвращает JWT и в теле (`routes/auth.ts:148`) — доступен JS, что снижает смысл HttpOnly; V3.3.4 прямо требует передавать значение HttpOnly-куки клиенту только через `Set-Cookie`.
- **Почему важно:** забытая рабочая станция остаётся авторизованной до 8 часов; администратор не может «выкинуть» пользователя, не деактивируя его.
- **Что сделать:**
  1. Решение (ADR): тайм-аут неактивности (например 30–60 мин) через поле `lastSeenAt` в JWT/кэше свежести либо скользящий короткий `exp` с абсолютным пределом; значения в env и в SECURITY_OVERVIEW с обоснованием по NIST SP 800-63B.
  2. Операция «завершить сессии пользователя» для администратора (`session_version + 1` + `revokeUserSessions`) и «выйти везде» для себя.
  3. Политика параллельных сессий — документировать (неограниченно) или ограничить.
  4. Убрать `token` из тела ответа входа, когда клиент — браузер (оставить для CLI по явному заголовку/параметру) — после проверки, что клиенты Taskira его не используют.
- **Критерий готовности:** тесты на тайм-аут неактивности и завершение сессий администратором; SECURITY_OVERVIEW и строки V7.x в ASVS-L2.md обновлены.
- **Не сделано:** ничего из перечисленного.
