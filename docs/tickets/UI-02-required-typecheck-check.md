# UI-02 — сделать CI-джобу `types` обязательной (required check)

**Статус: открыт, нужна настройка репозитория.** Заведено вместе с ТЗ 2.1 (PR 3).

- **Что есть:** джоба `types` в `.github/workflows/test.yml` запускает typecheck сервера и клиента в одном прогоне
  (клиент подтягивает `server/src/contract.ts`, поэтому правка серверных типов может сломать клиент).
- **Чего нет:** проверить/включить, что она *блокирует мерж*. Через API это не проверить и не включить:
  `gh api repos/Bakhtovar-SA/Taskira/branches/main/protection` и `/rulesets` отвечают 403 «Upgrade to GitHub Pro or
  make this repository public» — защита веток на текущем тарифе приватного репозитория недоступна. Без required check
  зелёный статус так же легко смёржить мимо, как раздельные джобы.
- **Что сделать:** включить защиту ветки/ruleset на `main` (тариф или публичный репозиторий) и добавить `types` (а
  также `server`, `client`) в обязательные проверки; либо договориться о процессе «не мержить при красном `types`».
