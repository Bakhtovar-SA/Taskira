# Ручная проверка трека K

01.10.2026, Windows, локальный Chromium, 300 карточек. Автоматическая проверка
`e2e/board-speed.pw.ts` выполняется в светлой и тёмной темах.

## Проверено автоматически

- [x] Загрузка 100 → 200 → 300 карточек и прокрутка до последней.
- [x] Фокус последней карточки и открытие меню клавишей M, Escape.
- [x] Открытие задачи с клавиатуры и готовое содержимое панели.
- [x] K и J переходят между последними задачами, сохраняя полный порядок DOM.
- [x] После закрытия панели все 300 карточек остаются в DOM.
- [x] Нативная модальность, удержание фокуса, Tab внутри панели и возврат фокуса на карточку.
- [x] Axe внутри основного содержимого без нарушений, обе темы.
- [x] Нет ошибок JavaScript в этих сценариях.
- [x] Production-замеры начала перетаскивания и dragover при смене колонок, CSP без нарушений.
- [x] Регрессии эпохи сессии: старые данные и 401 после нового входа игнорируются.
