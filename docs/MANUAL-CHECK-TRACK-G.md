# Ручная проверка трека G

Трек G перевёл ядро работы с задачами на `src/ds`: окна, меню, доску, список, карточку задачи и палитру команд. Шаги —
в [TRACK-G-DS-CORE.md](tracks/TRACK-G-DS-CORE.md), PR #103, #105–#108 и G6. Права и вызовы API не менялись. Проверять в
светлой и тёмной теме, на RU и EN, под администратором; проверки запретов — под сотрудником (чужая задача) и наблюдателем.

## Экраны

| Где | Что проверить глазами | Клавиатура |
|---|---|---|
| Создание задачи (`C`) | Окно открывается и закрывается плавно; шаблон, тип, приоритет, исполнители (аватары), метки, срок через календарь; подзадача — с зафиксированным родителем. | Фокус сразу в названии; Tab по полям; Esc закрывает, фокус возвращается на кнопку «Создать». |
| Импорт (Список → «Импорт») | Выбор файла, предпросмотр, флажок «включая закрытые», ход импорта, итоговый тост. | Tab по шагам, флажок — Space, Esc закрывает. |
| Массовые действия на доске | Панель снизу после выделения карточек; меню статуса, приоритета, исполнителя; подтверждение удаления. | Меню: стрелки, Enter, Esc закрывает только меню. Подтверждение: Esc отменяет. |
| Доска | Колонки и карточки как раньше, скелетоны при загрузке; метки — тоны; аватары с карточкой человека по клику. Меню «переместить» (стрелка на карточке): одновременно открыто только одно, закрывается кликом мимо. | `M`/`Ь` на карточке в фокусе открывает меню статусов; стрелки, Enter; Esc закрывает меню, фокус остаётся на карточке. |
| Список задач | Флажки строк и «выбрать все» (полуотмеченный, когда выбрана часть); метки и статусы — теги; скелетоны; меню колонок и фильтров. | Space на флажке; меню — стрелки/Enter/Esc. |
| Карточка задачи (клик по задаче) | Широкая панель справа, закрывается плавно. Статус, приоритет, сложность — меню; исполнители — список с галочками; направление и родитель — поиск; срок и свои поля-даты — календарь; чек-лист; метки; участники — поиск людей. Без права правки поля с замком, причина — в подсказке. | J/K — соседние задачи; Esc в правке названия отменяет только правку; Esc в открытом меню закрывает только меню; обычный Esc закрывает панель, фокус — на карточку доски. |
| Карточка на узком экране (< 768 px) | Правая колонка уходит под основное содержимое; горизонтальной прокрутки нет. | — |
| Задача полной страницей (из «Входящих», «Моих задач», поиска) | Открывается страницей, как раньше; ссылка `/p/KEY/issue/KEY-1` работает после обновления страницы. | — |
| Палитра команд (Ctrl+K / ⌘K) | Окно у верхней трети экрана, стекло; поиск разделов, проектов, задач; «Ищем «список»» для запроса в английской раскладке. | Курсор сразу в поиске; ↑/↓, Enter; Esc и повторный Ctrl+K закрывают; клик мимо закрывает; фокус возвращается. |
| Горячие клавиши (`?` или из палитры) | Обычное окно с крестиком, без фиолетовой рамки вокруг. | Esc закрывает. |
| Календарь (срок задачи и любой `DatePicker`) | Сетка по неделям как раньше; быстрые кнопки; ввод словами («завтра», «пт», «15.10»). Где заданы границы — дни вне них бледные и не выбираются, быстрые кнопки вне них неактивны, ввод вне них — «Вне допустимых дат». | Стрелки по дням, PageUp/PageDown — месяц, Home/End — неделя, Enter — выбрать, Esc — закрыть. |
| Кнопки-иконки с подсказкой (колокольчик, профиль, действия в карточке) | Подсказка появляется при наведении и фокусе с клавиатуры. | Меню у такой кнопки открывается и закрывается, фокус возвращается на кнопку. |
| Строка спринта (если модуль спринтов включён) | Аватары исполнителей — с карточкой человека по клику. | Enter на аватаре открывает карточку, Esc закрывает. |

## Проверки исполнителя

- Клиент: `npm run typecheck`, `npm test`, `npm run build`, `npm run bundle:check`, `colors`, `contrast`, `motion`,
  `antilist`, `npm run test:ui` (визуальные снимки и axe) — на каждом шаге.
- Chromium (Playwright) в обеих темах на каждом шаге — сценарии из колонки «Клавиатура» для доски, карточки, палитры и
  календаря; ошибок в консоли нет.
- Характеризующие тесты (`backlog.characterize`, `board.characterize`, `issueModal.characterize`, `palette.test`) —
  при переводе менялись только селекторы, утверждения те же.
- Не проверено вживую: реальная загрузка файлов в карточке и импорт большого файла (> 1000 карточек) — только тестами.


## Трек I — даты и прозрачность

Проверить в светлой и тёмной теме, включая клавиатуру и узкое окно.

| Где | Проверка |
|---|---|
| Новая задача → срок | Открыть календарь; выбрать день, ввести «завтра» и Enter, очистить. Сохранённый срок — ISO-дата, без изменения API. |
| Список → фильтр срока «с/по» | Вложенный календарь не закрывает меню фильтра. Выбор «с» позже «по» и «по» раньше «с» запрещён для ячеек, пресетов и ввода. Очистка сбрасывает соответствующий параметр URL. |
| Отчёты → период | Обе границы ограничивают друг друга. Выбор переводит период в «Свой»; очистка и пресеты сохраняют прежний формат запросов. Прошлые даты не красные. |
| Спринты → новый | Начало и конец через календарь. Конец не раньше начала; очистка отправляет null. Отмена и повторное открытие сбрасывают черновик. |
| Организация → аудит | Диапазон ограничен с обеих сторон; ссылка экспорта по-прежнему содержит начало дня для «с» и конец дня для «по». |
| Любое поле даты | Стрелки, Home/End, PageUp/PageDown; Enter выбирает, Esc закрывает только календарь и возвращает фокус на поле. |
| Личные настройки → оформление | «Как в системе», «Включена», «Выключена» сохраняются после перезагрузки. Проверить боковую панель, рабочий лист, меню и палитру Ctrl+K. |
| Системные настройки при открытой вкладке | Выключить прозрачность / включить повышенный контраст: при личном auto атрибут меняется сразу; при личном on стекло остаётся, появляется предупреждение про читаемость. |
| Организация → брендирование | Администратор сохраняет «Всегда включена», в личном auto появляется пояснение организации; обычному пользователю запись запрещена. «Как в системе» сбрасывает общий выбор. |
| Приоритеты | Личное off всегда выключает; личное on всегда включает; повышенный контраст при auto выключает даже при общем on. |
| Кэш бренда | Старый кэш без поля = auto; общий on без названия/оттенка сохраняется. Свежий ответ бренда сразу обновляет стекло, без перезагрузки. |

Автоматические проверки: `src/transparency.test.ts` — 24 сочетания и стартовый JS; `brand.test.ts` — кэш и свежий ответ;
`server/test/brand.test.ts` — миграция, публичное чтение, права, валидация и аудит; `e2e/track-i.pw.ts` — все поля дат,
фокус, прозрачность и axe в обеих темах. Linux-эталоны визуальной регрессии не перезаписывать снимками Windows.
