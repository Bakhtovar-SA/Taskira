# Ручная проверка трека J

Проверить RU и EN, светлую и тёмную темы. Автоматические аналоги: `e2e/calendar.pw.ts`,
`e2e/menu-anchor.pw.ts`, `CalendarView.test.tsx`, `dashboards.test.ts`.

- Кнопка «Ещё» дашборда: после наведения и повторных открытий меню остаётся рядом; Escape возвращает фокус.
- `/p/KEY/calendar`: месяц — шесть недель, неделя — одна; соседние месяцы и выходные видны; сегодня отмечено.
- Сегодня и стрелки меняют период. Режим запоминается после перезагрузки. Диапазон данных включает соседние дни.
- Поиск по ключу/названию, исполнитель, тип и «Скрыть закрытые» фильтруют также колонку «Без срока».
- Более трёх задач дня: «ещё N» открывает весь день. Неделя прокручивает задачи внутри ячейки.
- Плашки: тип, ключ, обрезка названия, аватар первого исполнителя; категории статуса, просроченность, зачёркнутые закрытые.
- Клик открывает правую панель; J/K идут по дням, включая скрытый хвост дня. Escape возвращает к сетке.
- Перенос задачи на другой день меняет срок. Из «Без срока» можно перенести в день; обратно — убрать срок.
- Сотрудник не может тащить чужую задачу; подсказка объясняет причину. Отказ PATCH не меняет положение, виден тост.
- M/Ь в фокусе задачи открывает выбор срока. Ввод словами/очистка работают, Escape возвращает фокус на плашку.
- «+» дня и Enter на дне создают задачу с этим сроком. Обычный «Создать» после закрытия не наследует дату.
- Стрелки по дням, PageUp/PageDown по периодам, T/Е на сегодня. Прежние 1–4 сохранены; 5 открывает календарь.
- Палитра находит calendar/календарь/kalendar. Календаря нет в выборе вида проекта по умолчанию.
- При >500 задачах диапазона видна строка ограничения; «Без срока» листается кнопкой «Показать ещё».
- Организационный обзор и шаблон «Портфель проектов»: состояния, вехи, таблица проектов; невидимых проектов нет.
- Проекты таблицы открывают свой Обзор. Веха открывает настройки сроков при editRoadmap, иначе роадмап.
- Встроенный обзор проекта показывает свои вехи при их наличии; каталог скрывает четыре портфельных виджета.
- Сохранённые личные наборы и старые обзоры не переписаны. Таймлайн и роадмап работают как прежде.

Снимки календаря сохраняются в артефакты Playwright для обеих тем и языков. Эталоны DS остаются Linux Chromium;
на Windows проверяется поведение и axe, без сравнения растеризации шрифта с Linux.
