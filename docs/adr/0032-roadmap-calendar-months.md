# ADR-0032 — Календарные месяцы роадмапа и отдельная колонка проектов

**Статус:** Accepted
**Дата:** 2026-10-05
**Supersedes:** ADR-0021 (частично: пункт 5, геометрия рендера)

## Контекст

Пункт 6 handoff требует фиксированных подписей проектов, строк 56 px и месяцев по 96 px.
Месяцы различаются числом дней: умножение дней на одну CSS-переменную из ADR-0021 не даёт
такую геометрию. Подписи, расположенные внутри старого холста, уходили при горизонтальной прокрутке.

## Решение

1. Сохранить общий `timeScale` и `TimeCanvas`. Опциональная ширина месяца включает координаты
   по доле календарного месяца; обычный Таймлайн сохраняет прежнюю линейную шкалу дней.
2. Передавать координаты видимых полос и вех в пикселях через CSSOM. Высоты проекта/отдела
   фиксированы: 56/40 px. В DOM остаётся окно строк плюс три строки запаса.
3. Отделить левую колонку 300 px от горизонтального холста; синхронизировать вертикальную
   прокрутку в обе стороны, учитывая высоту горизонтальной полосы прокрутки. Шапка шкалы
   44 px отдельно следует за горизонтальной прокруткой. На телефоне колонка занимает 180 px.
4. Вычислять градиенты на носителе цвета проекта из палитры `--project-1…8`. Для белого ключа
   использовать контрастные значения светлоты 0.50 → 0.52; проверять весь градиент всех восьми
   цветов во всех вариантах тем. Весь предварительный участок, включая часть под ключом,
   отмечать штриховкой.

Данные, права, серверный запрет циклов, принадлежность зависимостей, правило 28 предварительных
дней и расчёт прогресса по закрытым задачам из ADR-0021 сохраняются. Handoff уточняет визуальный
конфликт зависимости: конец предшественника строго позже начала зависимого; равенство допустимо.

## Последствия

При смене масштаба перерисовываются видимые строки, а не только одна CSS-переменная. Виртуализация
ограничивает эту работу независимо от числа проектов. Календарная координата согласована для
сетки, полос, вех, зависимостей и сегодняшнего дня, включая февраль и границу года.
