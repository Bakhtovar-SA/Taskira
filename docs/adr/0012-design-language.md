# ADR-0012 — Язык дизайна: фиолет 288, Onest, «тихий хром — живая атмосфера»

**Статус:** Superseded by ADR-0016
**Дата:** 2026-09-25 (реализация; палитра и шрифт выбраны владельцем на гейте ТЗ 5.3 22.09.2026)

## Контекст

Интерфейс был плоским: синий акцент `#0b5fd9`, тёмный сайдбар в обеих темах, «Segoe UI», капс-подписи с
трекингом, одна серая тень `rgba(20,35,64,…)` и 16 её вариантов, прямые hex в компонентах (сайдбар —
18 штук). Тёмная тема — отдельный набор hex без общей шкалы, поэтому любой новый экран выглядел «чужим» в
одной из тем. Владелец на гейте 5.3 выбрал: бренд — фиолетовая семья, тон 288 в OKLCH; нейтральная шкала того
же тона; шрифт Onest (ключи задач — JetBrains Mono); зерно на атмосфере 2 %/1 %; свечение бренд-оттенка в
углу холста. На реализацию владелец дал свободу в деталях (25.09.2026): две глубоко проработанные базовые темы,
«тихая роскошь» с ориентиром на Linear, допускается стекло, фиолетовый — акцентами.

## Решение

1. **Токены в три слоя** (`src/styles/tokens.css`): примитивы (`--violet-1…12`, `--gray-1…12`, статусы,
   палитра проектов) → семантика (`--bg-*`, `--text-1/2/3`, `--border-*`, `--accent-*`, `--status-*`,
   `--elev-0…4`) → алиасы старых имён `--c-*`. **Темы переопределяют только семантику** (и примитивы для
   тёмной шкалы). Tailwind-тема ссылается на токены, поэтому существующие классы (`bg-canvas`, `text-ink`…)
   продолжили работать без правки раскладки.
2. **Слои поверхностей**: `frame` (за боковой панелью, атмосфера) < `canvas` (рабочая область-«лист») <
   `panel` (карточки, поля) < `raised`/`overlay` (поповеры, диалоги). Тёмная тема: холст `oklch(0.182 …)`, не
   чёрный, каждый слой светлее на ≈0.03 L; глубина — ступенью светлоты и внутренним верхним бликом, а не
   тенью. Светлая: многослойные тени малой альфы, окрашенные в тон 288.
3. **«Тихий хром, живая атмосфера».** Хром (навигация, таблицы, формы, карточки) нейтрален; цвет в хроме
   только означает (акцент действия, статус, фокус). Атмосфера — за рабочей областью: свечение бренд-оттенка
   по углам (`--glow-a/b/c`) и зерно. Боковая панель прозрачна над атмосферой; рабочая область — вставленный
   «лист» со скруглением (приём Linear).
4. **Стекло** (`.glass`, `backdrop-filter`) — только хром: поповеры, меню, тосты, подсказки, шапка главной,
   карточка входа. Никогда на карточках задач и формах. Отключается при `prefers-reduced-transparency` и без
   поддержки `backdrop-filter`.
5. **Шрифты локально** в `src/assets/fonts/` (OFL): Onest variable — латиница + кириллица; JetBrains Mono —
   только латиница, потому что моно применяется только к ключам задач. Веса — 400/500/600 (`font-bold`
   убран во всём клиенте). Капс-подписи убраны во всём клиенте (73 места).
6. **Зерно** — готовая детерминированная плитка 160×160 (`scripts/generate-grain.mjs`), отдаётся файлом из
   сборки (> 4 КБ, Vite не инлайнит в `data:`), слой `body::before` с `mix-blend-mode` screen/multiply.
   «2 %/1 %» гейта трактуются как амплитуда модуляции светлоты: при шуме со средним 0.5 и разбросом ±0.3 это
   непрозрачность слоя 0.07 (тёмная) и 0.035 (светлая). Выключается в настройках «Текстура фона» и при
   `prefers-contrast: more`.
7. **Настройки внешнего вида** — атрибуты на `<html>`: `data-theme`, `data-atmosphere`
   (фиалка / сумерки / рассвет / сияние / графит — меняют только свечение), `data-texture`. Ни одного
   инлайн-стиля: прежний пресет фона писал `--c-canvas` в `style` корня.
8. **Проверки в CI** (job `client`): `npm run contrast:check` — все объявленные пары текст/фон обеих тем
   ≥ 4.5:1, элементы ≥ 3:1 (скрипт сам переводит OKLCH → sRGB); `npm run colors:check` — сырые hex/rgb/hsl
   вне `tokens.css` роняют сборку (исключение с причиной — `DIRECTION_COLORS`, hex хранится в БД).
9. **Знак** — «Две карточки»: перекладина и ножка «Т» — две карточки задач с зазором. Одноцветная версия
   (`<Logo mono />`) различает части зазором, не градиентом. Файл `public/favicon.svg` вместо `data:`-иконки.

## Последствия

- Любой экран автоматически живёт в обеих темах, если пишет цвет токеном; сырой hex не пройдёт CI.
- Кастомные темы (ТЗ 5.14) и брендирование инсталляции стоят дёшево: это переопределение семантического слоя.
- `oklch()` и `color-mix()` обязательны: Chromium 111+, Firefox 113+, Safari 16.4+ — совпадает с матрицей
  ТЗ 5.2 (две последние версии Chromium-браузеров, Firefox ESR, Safari 17+).
- Бандл: +90 КБ woff2 (два начертания Onest + латиница Mono, грузятся по `unicode-range`) и 25 КБ PNG зерна.
  JS не вырос.
- Не сделано в этом решении и остаётся за ТЗ 5.5–5.14: логотип не проходил проверку сходства с Т-Банк/T2/
  T-Mobile/Trello/Jira; плотность (`data-density`) и пользовательский режим движения не введены; фото-фон
  доски и курируемые темы сверх двух базовых — ТЗ 5.14; экраны переписаны по оформлению, но не по структуре
  (ТЗ 5.6/5.12).
