# ADR-0018 — Внешний вид проекта: иконка, цвет и фон — идентификаторы из закрытых списков

**Статус:** Accepted
**Дата:** 2026-09-27

## Контекст

ТЗ 5.10: в мастере создания проекта шаг 2 — «название, ключ, иконка, цвет», шаг 4 — «фон (необязательно)».
ADR-0017 оставил это отдельным решением: у проекта таких настроек не было, значок выводился из ключа (буква и тон
по хэшу ключа), а фон (атмосфера за рабочей областью) был только личной настройкой в `localStorage`. Владелец
27.09.2026 попросил сделать мастер полностью («сделай по красоте»).

Ограничения: CSP запрещает инлайн-стили, поэтому цвет из данных не может быть произвольным (ADR-0010);
«хром молчит» (ADR-0012/0016) — цвет проекта не должен превращаться в раскраску интерфейса; фото-фоны доски —
отдельный пункт ТЗ 5.14.

## Решение

1. У проекта три nullable-колонки (`projects.icon`, `color`, `background`, миграция `20260927T1400`), значения —
   **идентификаторы из закрытых списков** `contract.ts`: `PROJECT_ICONS` (20 иконок собственного набора),
   `PROJECT_COLORS` (10 фирменных тонов `tk-tone-*`), `PROJECT_BACKGROUNDS` (атмосферные пресеты `theme.ts`).
   Не hex и не URL: всё уже есть в токенах, CSP не нужен ни один новый стиль, темы (светлая/тёмная) работают сами.
   БД проверяет только форму значения — новый пункт списка не требует миграции.
2. `null` — прежнее поведение: буква ключа, тон по ключу, личный фон человека. Существующие проекты не меняются.
3. Фон проекта, пока проект открыт, **перекрывает** личный фон; на главной и вне проекта — личный.
4. Шаблон может предложить иконку (`spec.icon`, необязательно); при создании без явной иконки берётся она.
5. Меняет глобальный администратор — тем же `PATCH /api/projects/:id`, что и название (без нового `PermId`).
6. Знак проекта (`ProjectMark`) — единственное место, где видны иконка и цвет: боковая панель, шапка, палитра,
   главная, списки задач. Цвет проекта не красит ничего кроме знака.

## Последствия

- Проекты различимы в длинном списке без чтения названий; мастер закрывает шаги 2 и 4 ТЗ.
- Нельзя свой цвет или свою картинку — только из наборов. Фото-фон доски (ТЗ 5.14) — отдельное решение: ему нужны
  загрузка файла, затемнение под текст и хранение, а не идентификатор пресета.
- Фон проекта общий для всех участников: кто-то теряет свой личный фон внутри этого проекта. Поэтому у фона есть
  вариант «Личный» (значение `null`), и он по умолчанию.
