# ADR-0021 — Роадмап проектов: даты и вехи у проекта, зависимостями владеет зависимый, циклы запрещает сервер

**Статус:** Accepted
**Дата:** 2026-09-28

## Контекст

ТЗ 5.15: представление уровня организации — проекты полосами во времени, вехи, зависимости между проектами. На
сервере не было ни дат проекта, ни вех, ни связей. ТЗ запрещает Ганта по задачам, автоматический пересчёт дат по
зависимостям и «инициативы» над проектами; требует запрет циклов на сервере, права через матрицу, аудит, экспорт,
шкалу из примитивов Таймлайна и бюджет 5.2 на 100 проектах.

## Решение

1. **Данные** (миграция `20260928T1400_project_roadmap.sql`): `projects.start_date/target_date` (обе необязательные,
   CHECK порядка), `project_milestones` (название, дата, порядок вставки), `project_dependencies` (источник →
   зависимый, без петли на себя). Удаление проекта каскадом убирает его вехи и связи.
2. **Право `editRoadmap`** (admin, manager) — через матрицу. Зависимостью **владеет зависимый проект**: право нужно в
   нём, источник должен быть лишь виден пользователю (иначе 404, неотличимо от несуществующего). Смотрят роадмап все,
   кому виден проект; связь показывается, только если видны обе стороны.
3. **Цикл отклоняет сервер** (`409 DEPENDENCY_CYCLE`): рекурсивный запрос достижимости и вставка — в одной транзакции
   под одной advisory-блокировкой на весь граф. Граф маленький; иначе два встречных запроса прошли бы проверку оба.
4. **Неполные даты рисуются, а не прячутся**: одна дата — полоса продлевается на 28 дней штриховкой («не
   подтверждено»); без дат — строка с подписью «Сроки не заданы».
5. **Рендер:** шкала, сетка и «сегодня» — `timeScale.ts`/`TimeCanvas.tsx`. Строка хранит позиции в днях, пиксели
   считает CSS (`calc(дни × var(--ppd))`), и в DOM только строки в окне прокрутки — замер: смена масштаба на 100
   проектах 250 → 40 мс (1×), пересчёт стилей был основной долей.

## Последствия

- Даты по зависимостям не сдвигаются; «опаздывающая» связь только подсвечивается красным.
- Прогресс — доля закрытых задач проекта (включая архив), не вехи и не даты.
- Виртуализация требует фиксированной высоты строк (`ROW_H`, `GROUP_H` в `roadmapLayout.ts`); строка переменной
  высоты сломает линии зависимостей и окно.
