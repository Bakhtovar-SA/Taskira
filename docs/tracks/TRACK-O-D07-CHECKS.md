# Трек O — D-07: Undo подтверждённых изменений

Ветка `codex/track-o-undo`; база продукта `ff9c8ff`. Решение владельца: включить Undo.

Undo доступен после подтверждения сервером смены статуса (включая массовую), снятия метки или исполнителя. API возвращает только разрешённую обратную дельту и timestamp версии. Обратная операция повторно проверяет текущие права и workflow; CAS проверяется под row lock. Конфликт, архивирование и недоступность не перезаписываются. Повтор разрешён только после сетевой ошибки; уже применённая часть массовой операции не повторяется. Logout/смена проекта отменяют старый контекст.

Основная строка задачи, исполнители и спринт обновляют версию. Комментарии, чек-лист и другие отдельные дочерние таблицы этим токеном не защищены; Undo их не перезаписывает. Миграций и новых зависимостей нет.

Тост живёт 4200 мс, срок приостанавливается при фокусе и во время запроса. Кнопка остаётся фокусируемой с aria-busy/aria-disabled и имеет описание. Очередь ограничена четырьмя, очищается при смене сессии, поддерживает StrictMode reconnect. Намеренный новый фокус не перехватывается. Undo статуса использует снимок видимой доски перед обновлением.

Постоянный portal-хост интерактивного тоста переносится внутрь активного native dialog. Информационные тосты сохраняют прежний хост. Atomic moveBefore сохраняет узлы; fallback append мгновенно завершает вход и не воспроизводит его заново. Общий helper e2e идентичен A-06 (SHA256 38192603010E57E6839BA2FFB8F3626A70D96ADBA17F8D83E1A6A6078105F4A4).
