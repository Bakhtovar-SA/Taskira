# Трек O — D-08а: раскрытие «Ранее закрыто»

Ветка codex/track-o-done-disclosure, база258809c (C07 foundation). Сворачивание колонок как продукт не добавляется.

Недавняя часть «Готово» сохраняет свой closed=recent запрос, DOM и прокрутку. После нажатия отдельный closed=older запрос раскрывает старый хвост по grid0fr→1fr за --dur-3; строки используют существующий EnterTracker с cap8 (переполнение мгновенное, без очереди). Успешный ответ запускает раскрытие один раз; первоначальный URL done=1, смена фильтра/проекта, повторная загрузка и пагинация — baseline. При закрытии хвост снимается сразу; поздний ответ игнорируется.

Одна и та же нативная кнопка с aria-expanded остаётся на месте при открытии/закрытии. Исчезновение кнопки Retry возвращает фокус на disclosure, только если пользователь не выбрал другой элемент. Фокусная рамка помещается внутри scroll clipping. Unmount/cancel прекращают движение; retained entry IDs ограничены cap+1, без растущей истории страниц.

Серверные строки остаются authoritative. Лишь временно введённые локальным подтверждённым переносом строки проверяют recent/older окно: старая карточка при смене ранга не дублируется в recent. doneAt=null остаётся свежим. Счётчик older остаётся активен при раскрытии, чтобы кнопка не исчезала во время refetch.
