# Ручная проверка трека D — импорт Jira и Asana

Фикстуры в `src/import/__fixtures__/` составлены вручную по публичным инструкциям [Jira CSV export](https://support.atlassian.com/jira-software-cloud/docs/export-search-results/) и [Asana project export](https://help.asana.com/s/article/project-importing-and-exporting). Они проверяют поддерживаемую форму колонок, но не заменяют проверку на выгрузке из живого аккаунта.

1. В проекте с правом создания откройте «Список задач» → «Импорт». Проверьте три источника и подсказку для каждого; без права создания кнопки быть не должно.
2. Выберите Trello JSON и убедитесь, что прежний предпросмотр и импорт работают. Затем выберите Jira CSV из `src/import/__fixtures__/jira.csv`: показаны 9 задач, 1 пропущена, 1 срок не распознан. Закрытые задачи по умолчанию исключены; флажок включает их.
3. Выберите Asana CSV из `src/import/__fixtures__/asana.csv`: показаны 7 задач, 1 пропущена. Проверьте метки секций, типы и приоритеты после импорта.
4. Проверьте отмену во время импорта: после закрытия окна новые запросы на создание не отправляются. Повторный клик после завершения не создаёт дублей.
5. Попробуйте файл больше 20 МБ и CSV без обязательной колонки. Должна появиться понятная ошибка до создания задач.
6. Повторите открытие окна в русской и английской локали, в светлой и тёмной темах; проверьте управление с клавиатуры и axe. В рабочем списке проверьте, что исходные исполнители не назначились автоматически.
