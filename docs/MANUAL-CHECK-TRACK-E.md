# Ручная проверка — трек E (английский интерфейс)

Перед проверкой: `git pull`, `npm ci` в корне и в `server/`, запустить оба `npm run dev`. Две новые миграции
(`20260929T1500_activity_kind.sql`, `20260929T1510_users_lang.sql`) применятся сами при старте сервера.

- [ ] **Переключить язык:** аватар / «Оформление» → English. Пройти главную, доску, список, таймлайн, «Обзор» и
      дашборды, отчёты, роадмап, настройки (личные, проекта, организации), входящие, «Мои задачи», справку.
      Русский текст остаётся только в данных: названиях проектов, задач, команд, своих статусов, комментариях.
- [ ] **История задачи:** открыть задачу, поменять приоритет, срок, исполнителя, статус. Вкладка «History» по-английски
      («changed priority: Medium → High», «moved from “To do” to “In progress”»). Старые записи (сделанные до
      обновления) тоже по-английски, если это стандартная фраза. Переключить на русский — те же записи по-русски.
- [ ] **Массовая операция на доске:** «Select» → отметить карточки → поменять приоритет; в истории каждой —
      «(bulk action)».
- [ ] **Виджет «Activity»** на дашборде — те же строки по-английски.
- [ ] **Отказ в правах:** под сотрудником попробовать изменить чужую задачу — «The “Employee” role can edit and move
      only issues where you are the assignee or reporter».
- [ ] **Письма** (если включена почта): переключить язык на English, сделать так, чтобы пришло уведомление (назначить
      на задачу). Письмо и сводка — по-английски. Вернуть русский — следующее письмо по-русски.
- [ ] **Справка:** в English — раздел «Dashboards», «Teams and LDAP», актуальные горячие клавиши.
- [ ] **Подписи компонентов:** в English у поиска людей «Nothing found», у крестика в окнах подсказка «Close».
