# PERF-02 — Виртуализация карточек доски

Статус: open. Приоритет: high. Не входит в ТЗ 1.6.

## Наблюдение

Фикстура содержит 1 500 карточек в одной колонке. API-цикл восьми страниц при
200 пользователях дал p95 3 632 ms и p99 8 874 ms. После загрузки клиент хранит
весь активный набор и рендерит карточки без windowing; browser layout/paint в
API benchmark не входит, поэтому риск UI-фриза сохраняется отдельно от server
latency.

## Предлагаемая отдельная работа

Добавить виртуализацию колонок/карточек с сохранением drag-and-drop, фокуса и
доступности. Измерять PerformanceObserver/long tasks и память браузера на 1 500
и 5 000 карточках; оптимизацию API из PERF-01 оценивать отдельно.

## Критерий приёмки

На 1 500 карточках нет long task дольше 200 ms, взаимодействие и scroll не
теряют кадры сериями, DOM содержит только видимое окно с overscan.
