# PERF-03 — Bootstrap проекта под конкурентной нагрузкой

Статус: open. Приоритет: medium. Не входит в ТЗ 1.6.

## Наблюдение

`GET /api/projects/:projectId` выполняет шесть чтений параллельно. На 200
пользователях p95 составил 1 773 ms; на 100 пользователях — 821 ms. Ответ
включает пользователей, участников, workflow, шаблоны, поля и спринты, хотя
большая часть данных меняется редко.

## Предлагаемая отдельная работа

Профилировать шесть запросов отдельно, измерить ожидание пула PostgreSQL и
размер ответа. Рассмотреть ETag/conditional GET и кэширование неизменяемых
частей с явной инвалидацией, не объединяя работу с пагинацией задач.

## Критерий приёмки

p95 bootstrap при 200 пользователях не выше 750 ms, ноль ошибок и timeout;
метрики до/после приложены к тикету.
