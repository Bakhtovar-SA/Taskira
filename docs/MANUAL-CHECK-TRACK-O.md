## Запись прогона

Для каждого сценария сохранить: дату, commit сборки, ОС/устройство, точную версию браузера и движка,
язык, тему, системный/личный reduce, ширину viewport, масштаб ОС и zoom браузера. Результат — «ок»,
«дефект» или «не проверено»; при дефекте — шаги, ожидаемый/фактический результат и видео/ссылка на issue.
Пустая ячейка и наличие CSS API не считаются успешным прогоном.

## Профили

- RU и EN, светлая и тёмная темы.
- Системный reduce выкл/вкл × личный reduce выкл/вкл. При любом включённом — мгновенный корректный итог.
- Viewport 1920, 1460, 1024, 768, 390 px; отдельно 2560/3440 px с корневым CSS zoom 1.1.
- Windows scale 100/125/150%; отдельно записать zoom браузера (по умолчанию 100%).
- Обычная сеть; отдельно Slow 3G/задержка ответа >=600 мс и CPU 4× для быстрых последовательных действий.

Каждый применимый сценарий пройти на этих профилях, фиксируя комбинацию. Мобильный профиль выполняется
на настоящем устройстве, а scale Windows — на Windows. Неприменимость записывать с причиной.
