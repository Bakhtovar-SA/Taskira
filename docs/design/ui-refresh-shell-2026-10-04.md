# UI refresh — этап 1: оболочка

Реализован первый пункт `design_handoff_taskira_ui_refresh/README.md`.

Шапка проекта занимает одну строку высотой 52 px: проект, избранное, ссылки представлений,
участники, уведомления и кнопка «Задача». На телефонах вкладки прокручиваются внутри шапки,
действия имеют область нажатия 44 px. Поиск открывается через палитру Ctrl/Cmd K;
`/` фокусирует фильтр текущей доски или списка. Повторяющиеся заголовки этих экранов удалены,
счётчики задач сохранены в строке инструментов.

Боковая панель шириной 256 px объединяет поиск и кнопку новой задачи в один ряд.
Избранные проекты помечены звёздами в дереве. Счётчик «Мои задачи» читает назначения
по всем доступным проектам; для ограниченной выборки показывает «+».
Удалён блок прогресса проекта. Профиль, выход и три раздела настроек доступны снизу,
включая свёрнутую панель. Длинные названия обрезаются многоточием.

Использованы компоненты DS, семантические токены и словари RU/EN. HTML-референсы
остались в распакованной папке; их inline-стили не перенесены в приложение.

Эталоны оболочки сняты в Windows Chromium. На Linux эти сценарии проверяют размеры
и доступность; сравнение оболочки потребует собственных Linux-эталонов. Существующие
Linux-эталоны компонентов DS сохранены. Firefox/WebKit в этом этапе не запускались.
