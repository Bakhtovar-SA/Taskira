# Рабочая карточка: родитель и связи · 11 октября 2026

Согласованный [референс](reference.html) применён к IssueModal на локальном стенде. Baseline SHA: `da85515e04f6f5e07baa39cee4bbbdb3a9f95140`; проверяется рабочая копия с изменениями в ветке `codex/ui-audit-2026-10-09`.

- У обычной задачи нет постоянного поля «Родительская задача». Назначение доступно в «Действия → Сделать подзадачей».
- У подзадачи над названием показаны иконка, подпись, ключ и название родителя. Нажатие открывает родительскую задачу. «Изменить родителя» позволяет выбрать другого или сделать задачу самостоятельной.
- «Добавить связь» находится в «Действия». Тип связи выбирается кнопками Taskira, задача — штатным серверным поиском. Пустой блок «Связи» скрыт; сохранённые связи показывают тип, ключ и название, с переходом и удалением для доступных пользователю действий.
- «Направление» и блок «Подзадачи» сохранены. Задача с детьми не может стать подзадачей; для подзадачи создание ещё одного уровня скрыто. Наблюдателю доступны родитель и существующие связи, изменения скрыты.
- Escape закрывает поиск и возвращает фокус в «Действия». Клик вне поиска закрывает его, оставляя карточку открытой. На телефоне свойства раскрываются прежней кнопкой «Остальные свойства».

Impeccable и Taste Frontend UI Engineering применены для сохранения плотности, типографики и дизайн-системы. Масштаб интерфейса и API-контракты не менялись. Связи остаются информационными: блокировка переходов по workflow не добавлена.
