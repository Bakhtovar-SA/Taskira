# Референс карточки: родитель и связи · 11 октября 2026

Макет создан из действующей карточки UX-3 при 1920×1080, с теми же шрифтом, плотностью, цветами и основными блоками. Impeccable и Taste Frontend UI Engineering использованы для сохранения дизайн-системы и постепенного раскрытия редких действий.

Пустые поля «Родительская задача» и «Связи» убраны. Родитель появляется только у подзадачи — компактной строкой над названием. В меню добавлены «Сделать подзадачей» / «Изменить родителя» и «Добавить связь». Блок связи показывается при наличии связи. «Подзадачи» и «Направление» сохранены. В состоянии подзадачи скрыто создание ещё одного уровня вложенности, как в существующих бизнес-правилах.

[Открыть интерактивный референс](http://localhost:3000/docs/design/issue-relations-reference-2026-10-11/reference.html). Три переключателя сверху показывают обычную задачу, подзадачу и задачу со связью; можно открыть меню действий. На мобильном раскрывается блок «Остальные свойства».

[Обзор с меню](overview.png) · [Обычная задача](plain.png) · [Подзадача](parent.png) · [Со связью](links.png) · [Меню крупнее](actions-detail.png) · [Мобильный экран](mobile.png) · [До](before.png).

Родитель UX-1 и связь с UX-9 в макете условные, названия взяты из настоящих тестовых задач. Данные задач и код приложения не изменены. В прототипе работают только переключение демонстрационных состояний, меню и раскрытие свойств; сохранение, удаление и прочие действия карточки не подключены к API.

Снимки сделаны браузером в исходном масштабе, без растрового редактирования. Проверены видимость ключевых блоков, переключение состояний и отсутствие горизонтального переполнения при 390×844. [Метаданные](reference.json), [генератор](create-reference.mjs). Стенд localhost:3000 должен работать для загрузки шрифта в HTML-референсе.

Вариант применён к рабочей карточке. [Отчёт и проверки](report.md) · [открыть UX-3 на стенде](http://localhost:3000/p/UX/board?issue=UX-3). Исходный HTML-референс выше остаётся отдельным макетом; его переключатели не добавлены в продукт.
