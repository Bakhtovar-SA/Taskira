# Обновление UI — пункт 7: Отчёты и дашборды

Дата: 2026-10-05. Основание: `design_handoff_taskira_ui_refresh/README.md`, пункт 7.

Сделана общая организационная шапка высотой 52 px с названием «Отчёты и дашборды».
Крошки проекта нет; вкладки — ссылки DS: «Обзор организации», «Задачи за период»,
пользовательские дашборды и кнопка «+ Дашборд». На мобильном экране есть открытие
панели навигации. Встроенные виджеты обзора, права и редактор дашбордов сохранены.

Периодный отчёт использует сегменты 30 дней / Квартал / Год, два DatePicker,
меню отдела и выбор нескольких проектов через Popover и Checkbox. Нативных
select нет. Выбор нуля проектов показывает пустое состояние и не превращается
в запрос всех проектов. Смена отдела возвращает выбор всех проектов этого отдела.
CSV-срезы закрытых, созданных и открытых задач находятся в меню «Экспорт» справа.

Пять отдельных плиток используют сетку `repeat(5, minmax(0, 1fr))`, радиус 12 px,
числа 30/700 с табличными цифрами. Закрытое и просрочка окрашены семантическими
токенами. Среднее время дополняется медианой. Ниже — график и таблица в пропорции
1.25:1; две серии используют `--chart-1` и `--chart-3`, значения подписаны над
столбцами. График имеет табличное представление и клавиатурную прокрутку.
Пустой период скрывает плитки и показывает одно состояние со сбросом фильтров.

Сервер добавляет созданные задачи к недельному тренду, включая нулевые недели,
и текущую просрочку к строкам разбивки. Проекты, где за период были только
созданные задачи, больше не выпадают из таблицы. Необязательные поля ответа
совместимы с прежними потребителями. `projectIds` применяется к JSON и CSV;
сервер пересекает его с видимыми проектами и прежними фильтрами.

Пресет 30 дней теперь содержит ровно 30 календарных дат. Сравнение запрашивает
непосредственно предшествующий период такой же длины с теми же фильтрами.
Нулевая база подписана числом; ошибки сравнения не скрывают текущую сводку;
запоздавший ответ не заменяет новый период. Открытые и просроченные задачи
подписаны «На текущую дату»: API хранит текущее состояние, а не исторические
снимки. Для этих двух плиток историческая дельта не вычисляется.

«Empty» был задан общей e2e-фикстурой — фикстура теперь возвращает пустой список.
Отдельный тест подтверждает, что настоящий личный дашборд с названием «Empty»
и без виджетов остаётся доступен и редактируем. База данных не очищалась,
фильтрации по имени дашборда нет. Архитектурное решение описано в ADR-0033;
ADR-0022 изменён только в строке статуса.

Цвета берутся из tokens.css, оформление находится в `src/styles/reports.css`,
динамическая ширина SVG передаётся через CSSOM. HTML и inline-стили из пакета
не копировались. Новых зависимостей нет. Неиспользуемые строки прежнего отчёта
удалены из обоих словарей; база и допуски bundle-budget.json сохранены.

  серьёзных и критических нарушений axe нет, нарушений CSP нет. Светлый и тёмный
  снимки дополнительно просмотрены вручную.
- 18 прежних визуальных сценариев доски, списка и Главной прошли сравнение
  без обновления эталонов.
- Прежний тест меню личного дашборда (`menu-anchor.pw.ts`) прошёл с отдельной
  фикстурой пользовательского дашборда.
- `colors:check`, `contrast:check`, `motion:check`, `antilist:check`,
  `permissions:check`, `docs:check`, `build`, `bundle:check`, `git diff --check`.
