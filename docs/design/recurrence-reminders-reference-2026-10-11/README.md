## Предложение

При создании два пункта доступны под основными параметрами: «Повторение» и «Напомнить мне». Для существующей задачи они находятся в начале «Действия». После выбора состояние появляется рядом со статусом. Пустые постоянные поля в карточку не добавляются.

Повторение создаёт новую задачу из данных проекта: ежедневно, по выбранным дням недели или по числу месяца. Есть интервал, первый день, время, часовой пояс, пропуск пока предыдущая задача открыта и три ближайших повтора. Личное напоминание уведомляет только выбравшего его пользователя: через час, три часа, вечером, завтра, через неделю, месяц, за день до срока или в выбранные дату и время.

## Граница реализации

Это интерактивный визуальный макет. Его состояние хранится только в открытой странице. Задачи, правила и напоминания не записываются в приложение; кнопка создания показывает пояснение.

У существующего API повторения обязательный templateId. Для контекстного создания потребуется снимок данных формы/задачи в шаблон и создание правила через существующий API с действующими правами. На стенде планировщик сейчас выключен: recurring/config.enabled=false, defaultTimeZone=Asia/Tashkent. Макет показывает предлагаемый вид функции после подключения, настройка сервера сохранена.

Точное личное напоминание на отдельную задачу требует новой записи на сервере и доставки уведомления. Текущие общие настройки [7,3,1,0] дней до срока не заменяют это поведение. Расчёт макета использует демонстрационные дату и время: 11.10.2026, 16:30, Ташкент. В реализации ближайшие даты должны приходить из серверного preview, а быстрые напоминания рассчитываться от текущего времени пользователя. Последний день месяца и выбор часового пояса поддержаны существующим API, но не представлены отдельными переключателями в этом локальном варианте.
