# UI refresh — этап 3: панель задачи

Реализован третий пункт handoff README в существующем `IssueModal`.

Панель имеет ширину 980 px на экране 1440 px, отступы 8 px, радиус 16 px,
тень `--elev-4` и подложку `--bg-scrim`. Шапка высотой 52 px содержит тип,
проект, ключ, навигацию с подсказками K/J и действия. Прежний баннер с
объяснением клавиш удалён. Границы кнопок навигации и статуса заданы явно
через `--border-default`: существующая составная тень вторичной кнопки DS
использует числовой `--shadow-tint` как цвет и не создаёт границу в браузере.
Изменение ограничено кнопками панели.

Заголовок 26 px редактируется по клику и с клавиатуры. Рядом со статусом
появляется первый настроенный переход в следующую категорию workflow,
если у пользователя есть право перехода. Название встроенного начала работы
локализовано как «Взять в работу»; остальные переходы используют имя статуса.
Создатель и дата показаны нейтральным текстом.

Описание отображается без фоновой плашки. Подзадачи, чек-лист и вложения
собраны в три одинаковые плитки. Длинный текст пункта чек-листа переносится.
Файлы можно перетаскивать в любое место панели; загрузка использует прежние
проверки и API, а разрешение определяется правом комментирования.

Правая колонка шириной 320 px показывает свойства без блока «Дополнительные
свойства»: статус, исполнителей, приоритет, срок, сложность, направление,
родительскую задачу, метки и пользовательские поля. Спринт отображается,
когда модуль включён в проекте. Сохранены связи, приглашение гостей и
подписка с откатом состояния при ошибке API. Просрочка показана текстом с
числом календарных дней, включая режим читателя; закрытый статус её снимает.

Лента использует настоящие вкладки DS с `tablist`, `tab`, связанными
`tabpanel` и навигацией стрелками. Счётчики комментариев и истории обновляются.
Поле комментария расположено после ленты и доступно в любом её режиме;
Ctrl+Enter отправляет сообщение. Пустое сообщение не отправляется, при этом
кнопка сохраняет читаемый мягкий акцент. Подписи панели — от 12 px, аватары
— от 22 px; инициалы используют стандартный размер аватаров DS.

На мобильных сохранён порядок «заголовок → свойства → содержимое». Важные
кнопки и поля имеют высоту 44 px. Действия, скрытые в компактной шапке,
доступны в меню. Полная страница задачи использует тот же компонент.

Все новые строки добавлены в RU и EN. Цвета используют существующие
семантические токены, динамические цвета задаются через CSSOM. HTML и
inline-стили референса в приложение не копировались.

## Проверки

- `typecheck`, `colors:check`, `contrast:check`, `motion:check`, `antilist:check`
  — успешно.
- Полный `npm test -- --maxWorkers=2 --testTimeout=20000 --hookTimeout=20000`
  — 90 файлов, 716 тестов успешно. Первый запуск не смог запустить два
  worker-процесса; повтор без одновременной сборки прошёл. Конфигурация тестов
  не изменена.
- После финальных правок панели повторно пройдены 24 её поведенческих теста.
- `build` и `bundle:check` — успешно. JS + CSS gzip: 352.39 КиБ, рост
  155.90 КиБ при существующем допуске 156 КиБ. Бюджет не изменён.
- Production с CSP: 29 браузерных сценариев успешно. Проверены переходы,
  подписка, комментарии с клавиатуры, права читателя, загрузка файла через
  drop, порядок и размеры на 320/390 px, создание задачи и общие панели
  доски/списка. Нарушений CSP в проверяемых действиях нет.
- Визуальные сценарии панели: шесть тем — light, dark, dusk, graphite, dawn,
  paper. Проверены размеры 980/52/320 px и границы кнопок; снимки
  `e2e/__screenshots__/issue-*-win32.png` обновлены и просмотрены визуально.
  Axe не обнаружил serious/critical нарушений; мобильный аудит существующих
  форм также прошёл.
- `git diff --check` — без ошибок пробелов.

Проверки выполнены в Windows Chromium 141 / Playwright 1.56.1 с моками API.
Firefox/WebKit и реальный сервер не проверялись. Linux-сценарии проверяют
размеры и доступность; для сравнения изображений нужны отдельные эталоны.
