# UI refresh: список — 04.10.2026

Выполнен пункт 4 handoff `design_handoff_taskira_ui_refresh/README.md`.
Предыдущие изменения оболочки, доски и панели задачи сохранены.

Список и доска используют общие поиск и быстрые фильтры в `WorkspaceControls`.
Группировка списка по умолчанию — статус, в порядке workflow. Доступны также
направление, набор исполнителей и отсутствие группировки. Режим сохраняется
в URL. При нескольких исполнителях задача находится в группе их общего набора
и отображается один раз; порядок идентификаторов исполнителей на это не влияет.

Группируются загруженные серверные страницы. Фильтрация, сортировка и
пагинация остаются на сервере. Счётчик статуса показывает `загружено/всего`,
пока загружены не все задачи группы. Для направления и исполнителей указано
количество загруженных задач, с соответствующей подсказкой. Группы без
загруженных строк появятся при подгрузке следующих страниц.

Таблица занимает всю ширину с отступами 18 px и радиусом 12 px. Новые настройки
по умолчанию: приоритет 28 px, ключ 76 px, название с многоточием, направление
230 px, срок 110 px и исполнитель 74 px. Сохранённые настройки колонок человека
сохраняют приоритет. Заголовки имеют высоту 34 px, группы — 36 px, строки —
40/36 px по плотности DS. Сроки используют локальный календарный день и
семантические цвета срочности; закрытые строки имеют отдельный фон.

Статус и исполнители меняются через DS Menu/Popover без открытия задачи,
с проверкой workflow и прав. «+» в группе статуса открывает общий с доской
компонент быстрого создания. Сохранены ссылки на задачи, выбор строк,
массовые действия, сохранённые фильтры и импорт. Мобильный порядок из
ADR-0027 сохранён: название с ключом, затем статус и исполнитель, доступное
меню; цели нажатия — 44 px. Промежуточные ширины прокручивают таблицу внутри
представления.

Добавлен семантический `--bg-group`: точное светлое значение референса,
темы и скины используют собственный `--bg-sunken`. Проверка контраста
включает текст групп. Все новые строки есть в RU и EN. HTML референса и
inline-стили не переносились; динамический цвет направления задаётся CSSOM.

Для сохранения прежнего бюджета повторяющийся тулбар вынесен в общий
компонент. Базовые UI-примитивы, уже загружаемые оболочкой, собраны в
`ui-core` через `rolldownOptions.output.codeSplitting`; экраны сохраняют
ленивые импорты. До первого экрана загружается меньше JS, чем до изменения
сплиттинга (174,68 против 176,33 КиБ gzip). Допуски и база не менялись.
