# UI refresh — пункт 6: роадмап

05.10.2026. Выполнен пункт 6 из `design_handoff_taskira_ui_refresh/README.md`.

Экран получил шапку 52 px с количеством проектов и отделов, фильтром отдела,
масштабом и кнопкой «Сегодня». Колонка проектов занимает 300 px на компьютере
и 180 px на телефоне. Горизонтально прокручивается только шкала; вертикальная
прокрутка синхронизирована в обе стороны, включая конец длинного списка.
Группы отделов имеют высоту 40 px, проекты — 56 px, марки проектов — 24 px.
Под названием показана ближайшая сегодняшняя или будущая веха, справа —
число закрытых задач из общего числа. Если будущих вех нет, показаны сроки.

Общий `timeScale` получил опциональный календарный режим: полный месяц
занимает ровно 96 px, включая февраль високосного года. Шапка шкалы — 44 px,
сегодняшний день — линия 2 px и метка 16 px над месяцем. Годы подписаны над
месяцами. Обычный Таймлайн сохраняет прежнюю геометрию.

Полосы высотой 26 px и радиусом 7 px используют палитру `--project-1…8`,
градиент, мягкую тень и пунктир оставшейся части. Минимальные 68 px дают
читаемую подложку ключу проекта; точный прогресс также виден в счётчике и
доступном имени полосы. Весь предварительный участок отмечен штриховкой,
включая часть под ключом. Вехи — контурные ромбы с подписью справа. Веха,
попадающая в область ключа, поднята внутри той же строки, чтобы не закрывать
буквы. Легенда на компьютере занимает 40 px, на телефоне переносится.

Зависимость красная только при `pred.end > succ.start`; равенство дат допустимо.
Фильтр отдела убирает строки других отделов и связи, один конец которых скрыт.
Шестерёнки заменены меню строки из DS. Кнопка «+ Задать сроки» открывает
существующие настройки проекта; без `canEdit` она недоступна с объяснением.
Серверные права, модель данных и правила сохранения сроков не менялись.

HTML из handoff не копировался. Цветовые формулы находятся в `tokens.css`,
оформление — в `roadmap.css`, динамические позиции передаются через CSSOM.
Для белого ключа светлота градиента скорректирована до 0.50 → 0.52: исходные
0.56 → 0.66 не дают достаточного контраста. Минимальный проверенный контраст —
4.71:1 по 11 точкам каждого из восьми градиентов во всех 24 вариантах тем,
прозрачности и повышенного контраста. Текст не меньше 12 px; цели на телефоне
не меньше 44 px. Архитектурное изменение описано в ADR-0032; старый ADR-0021
изменён только в строке статуса.

Для сохранения бюджета два временных представления объединены в общий
лениво загружаемый чанк. Уже загружаемые при старте поверхности DS объединены
с общими примитивами. Итог gzip: JS + CSS 352.05 КиБ при лимите 352.49 КиБ;
JS 320.73 КиБ, CSS 31.33 КиБ, входной чанк 95.62 КиБ. JS до первого экрана
174.42 КиБ. База и допуски `bundle-budget.json` сохранены, зависимостей не добавлено.
