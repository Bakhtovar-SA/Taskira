# Taskira — язык дизайна

Решения и причины — [ADR-0012](../adr/0012-design-language.md) и [ADR-0016](../adr/0016-design-language-v2.md) (шрифт, стекло, знак, иконки). Здесь — как этим пользоваться.

## Принцип

**Тихий хром, живая атмосфера.** Навигация, таблицы, формы и карточки нейтральны; цвет в них означает
(действие, статус, фокус) и никогда не украшает. Выразительность — только в атмосфере за рабочей областью:
свечение тона 288 (зерна нет). Стекло — только на хроме: боковая панель, рабочий лист, поповеры, меню, тосты, подсказки.

## Токены

Файл: `src/styles/tokens.css`. Новый код пишет **семантические** имена.

| Роль | Токен | Класс Tailwind |
|---|---|---|
| Фон за боковой панелью (атмосфера) | `--bg-frame` | `bg-frame` |
| Рабочая область («лист») | `--bg-canvas` | `bg-canvas` |
| Утопленные зоны (колонки доски, поля поиска, правая панель задачи) | `--bg-sunken` | `bg-sunken` |
| Карточки, поля, таблицы | `--bg-panel` | `bg-panel` |
| Поповеры / диалоги | `--bg-raised` / `--bg-overlay` | `bg-raised` / `bg-overlay` |
| Наведение / нажатие в списках | `--bg-hover` / `--bg-active` | `hover:bg-hover` / `bg-active` |
| Текст: основной / вторичный / приглушённый | `--text-1/2/3` | `text-ink` / `text-sub` / `text-faint` |
| Текст на акценте | `--text-on-accent` | `text-onaccent` |
| Границы | `--border-subtle/default/strong` | `border-linesoft` / `border-line` / `border-line2` |
| Акцент: заливка / текст / подложка | `--accent-solid` / `--accent-text` / `--accent-subtle` | `bg-accent` / `text-accenttext` / `bg-accentsoft` |
| Подъём | `--elev-1…4` | `shadow-e1…e4` |
| Кольцо фокуса | `--focus-ring` | `shadow-focus` (глобально — `:focus-visible`) |

Готовые поверхности: `.surface-sheet` (рабочая область), `.surface-raised` (карточка с верхним бликом),
`.glass`, `.glass-side`, `.glass-sheet` + `.glass-edge` (стекло хрома), `.btn-primary` (основная кнопка с бликом и мягким свечением).

**Тёмные поверхности, 13.10.2026. Supersedes численное значение холста в ADR-0012, п. 2.**
По запросу владельца все тёмные темы немного осветлены. Ступени `frame / canvas / sunken / panel`
теперь равны `0.17 / 0.21 / 0.19 / 0.24` в базовой тёмной теме, `0.16 / 0.20 / 0.18 / 0.23`
в «Сумерках» и `0.18 / 0.21 / 0.19 / 0.24` в «Графите» (светлота OKLCH).
Поле ввода на `--bg-sunken` остаётся темнее холста и карточки на `--bg-panel`; границы тоже подняты
на соседнюю ступень. ADR-0012 сохраняет исходное решение и историческое значение `0.182`.

Радиусы: `rounded-sm` 4 · `rounded-md` 6 · `rounded-lg` 10 · `rounded-xl` 14 · `rounded-2xl` 20. Вложенный
радиус = внешний − отступ.

Движение: `--dur-1…5` (100/150/200/300/450 мс), `--ease-out`, `--ease-standard`. Ничего дольше 450 мс; при
`prefers-reduced-motion` — только прозрачность.

## Типографика

Manrope 400/500/600, 700 — только заголовки и словесный знак. Заголовок экрана — 20 px / 600–700 / −0.02em;
главная — 28–30 px. Основной текст и кнопки — 15 px, мелкие подписи — 13–14 px / 500–600, **без капса**.
Плотная компоновка сокращает отступы и высоту элементов, сохраняя размер текста. Ключи задач (`CORP-12`) — класс `font-mono`,
это тот же Manrope с табличными цифрами; числа, даты, счётчики — `tabular`. Код — `--font-code` (системный).

## Иконки и знак

Иконки — `src/icons.tsx`, двухтоновые (`.s` рисунок, `.t` тон), сетка 16, края на целых пикселях. Тон раздела —
проп `tone` (`violet`, `teal`, `pink`…). Глифы: `StatusGlyph`, `PriorityIcon`, `DueRing`. Знак — `<Logo>`:
`mark` (основной, один цвет), `mono` (currentColor), `app` (плашка, только иконка приложения).

## Правила, которые проверяет CI

- `npm run contrast:check` — пары текст/фон обеих тем ≥ 4.5:1, элементы интерфейса ≥ 3:1.
- `npm run colors:check` — никаких hex/rgb/hsl вне `tokens.css` (исключения с причиной — в самом скрипте).
- `npm run motion:check` — длительности только из токенов `--dur-*`, не дольше 450 мс, всё движущееся переопределено под
  `prefers-reduced-motion` (ТЗ 5.13).
- `npm run antilist:check` — текстовая часть списка «Нельзя»: капс-подписи (`uppercase`; заглавная первая буква —
  `first-letter:uppercase` — можно) и стрелка «→» в конце текста кнопки (ТЗ 5.16).
- Акцент бренда: оттенок `--brand-h` из диапазона `BRAND_HUE` (255–320, `contract.ts`) — `contrast:check` проверяет
  все пары для каждого оттенка диапазона во всех темах (ТЗ 5.14 п.5).

## Нельзя

Градиент как украшение карточки; стекло на карточках и формах; капс-подписи; стрелка «→» в тексте кнопок;
моноширинный шрифт для всего мелкого подряд; одна серая тень под всем подряд; сырой hex в компоненте.

## Плотность desktop · доводка 10 октября 2026

После пользовательского просмотра основной рабочий размер принят 1920×1080 при масштабе браузера 100%. При точном указателе и ширине от 1024 px рабочий текст карточек — 13 px, кнопки — 32 px, боковая панель — 248 px. От 2560 CSS px действует отдельный профиль: карточки 16 px, кнопки 38 px, панель 304 px; профиль 1920 не меняется. Значения задаются переменными плотности в `workspace.css`. По последнему запросу пользователя от 2560 CSS px применяется общий коэффициент масштаба 1.1 для текста, иконок, кнопок и отступов; профиль 1920 сохраняется. Всплывающие поверхности и высота диалогов учитывают этот коэффициент. Шрифт, семантические цвета и иерархия остаются общими. Touch и мобильные размеры сохраняют зоны нажатия от 44 px. Полный разбор: [доводка](refinement-2026-10-10/report.md).


## Контекстное выделение и панели списка · 11 октября 2026

Список позволяет выделять задачи прямо в строках. Место под чекбокс постоянно зарезервировано; сам чекбокс виден при наведении, фокусе с клавиатуры или активном выборе. На touch он виден всегда. Выбранные строки получают тон акцента. Массовые действия находятся в компактной панели у нижнего края рабочей области, с отдельным меню полей и отделённым удалением. Escape закрывает сначала вложенное меню, затем панель действий, затем снимает выделение. Режим «Выделить» на доске сохраняется.

«Фильтры» и «Вид» — привязанные всплывающие панели на штатном Popover API; строки не меняют положение при раскрытии. Фильтры организованы по полям с иконками и текущим значением. Вид показывает сортировку и переключатели колонок с доступным состоянием выбора. На телефоне счётчик и группировка занимают свою строку, а кнопки панелей остаются рядом и доступны. Иконка неназначенного исполнителя — человек в пунктирном круге. В месячном календаре задачи прокручиваются внутри дня, а «ещё N» остаётся в границах ячейки.

Подробности и снимки: [выделение и меню](list-selection-2026-10-11/report.md).

Внутренние значения фильтров тоже раскрываются штатным Menu Taskira с галочкой выбранного значения и семантическими глифами; системные select в панели не используются. У пустого исполнителя одна пунктирная окружность в SVG, без внешней CSS-рамки и размытия. Интерактивные аватары показывают профиль по наведению/фокусу без перехвата фокуса; клик закрепляет полную карточку, touch использует клик. Показываются только данные текущего пользователя в store.

## Регулируемый сайдбар · 11 октября 2026

Команда — статичный заголовок, под ней раскрываемый раздел «Проекты» без фона и обводки. Правый край меняет ширину панели в пределах 220–420 CSS px; размер сохраняется локально. Перетаскивание дальше минимума сворачивает панель с сохранением предыдущей ширины, двойной щелчок сбрасывает размер к профилю экрана. На desktop одна линия 2 px обозначает активное перетаскивание и гаснет при отпускании; клавиатурный фокус обозначается одной линией 3 px. Подробности и свидетельства: [референс и внедрение](sidebar-reference-2026-10-11/README.md).
