# Taskira — язык дизайна

Решения и причины — [ADR-0012](../adr/0012-design-language.md) и [ADR-0016](../adr/0016-design-language-v2.md) (шрифт, стекло, знак, иконки). Здесь — как этим пользоваться.

## Принцип

**Тихий хром, живая атмосфера.** Навигация, таблицы, формы и карточки нейтральны; цвет в них означает
(действие, статус, фокус) и никогда не украшает. Выразительность — только в атмосфере за рабочей областью:
свечение тона 288 (зерна нет). Стекло — только на хроме: боковая панель, рабочий лист, поповеры, меню, тосты, подсказки.

## Токены

Файл: `src/styles/tokens.css`. Новый код пишет **семантические** имена.

| Роль | Токен | Класс Tailwind |
|---|---|---|
| Фон за боковой панелью (атмосфера) | `--bg-frame` | `bg-frame` |
| Рабочая область («лист») | `--bg-canvas` | `bg-canvas` |
| Утопленные зоны (колонки доски, поля поиска, правая панель задачи) | `--bg-sunken` | `bg-sunken` |
| Карточки, поля, таблицы | `--bg-panel` | `bg-panel` |
| Поповеры / диалоги | `--bg-raised` / `--bg-overlay` | `bg-raised` / `bg-overlay` |
| Наведение / нажатие в списках | `--bg-hover` / `--bg-active` | `hover:bg-hover` / `bg-active` |
| Текст: основной / вторичный / приглушённый | `--text-1/2/3` | `text-ink` / `text-sub` / `text-faint` |
| Текст на акценте | `--text-on-accent` | `text-onaccent` |
| Границы | `--border-subtle/default/strong` | `border-linesoft` / `border-line` / `border-line2` |
| Акцент: заливка / текст / подложка | `--accent-solid` / `--accent-text` / `--accent-subtle` | `bg-accent` / `text-accenttext` / `bg-accentsoft` |
| Подъём | `--elev-1…4` | `shadow-e1…e4` |
| Кольцо фокуса | `--focus-ring` | `shadow-focus` (глобально — `:focus-visible`) |

Готовые поверхности: `.surface-sheet` (рабочая область), `.surface-raised` (карточка с верхним бликом),
`.glass`, `.glass-side`, `.glass-sheet` + `.glass-edge` (стекло хрома), `.btn-primary` (основная кнопка с бликом и мягким свечением).

Радиусы: `rounded-sm` 4 · `rounded-md` 6 · `rounded-lg` 10 · `rounded-xl` 14 · `rounded-2xl` 20. Вложенный
радиус = внешний − отступ.

Движение: `--dur-1…5` (100/150/200/300/450 мс), `--ease-out`, `--ease-standard`. Ничего дольше 450 мс; при
`prefers-reduced-motion` — только прозрачность.

## Типографика

Manrope 400/500/600, 700 — только заголовки и словесный знак. Заголовок экрана — 20 px / 600–700 / −0.02em;
главная — 28 px. Подписи полей — 12–12.5 px / 500–600, **без капса**. Ключи задач (`CORP-12`) — класс `font-mono`,
это тот же Manrope с табличными цифрами; числа, даты, счётчики — `tabular`. Код — `--font-code` (системный).

## Иконки и знак

Иконки — `src/icons.tsx`, двухтоновые (`.s` рисунок, `.t` тон), сетка 16, края на целых пикселях. Тон раздела —
проп `tone` (`violet`, `teal`, `pink`…). Глифы: `StatusGlyph`, `PriorityIcon`, `DueRing`. Знак — `<Logo>`:
`mark` (основной, один цвет), `mono` (currentColor), `app` (плашка, только иконка приложения).

## Правила, которые проверяет CI

- `npm run contrast:check` — пары текст/фон обеих тем ≥ 4.5:1, элементы интерфейса ≥ 3:1.
- `npm run colors:check` — никаких hex/rgb/hsl вне `tokens.css` (исключения с причиной — в самом скрипте).

## Нельзя

Градиент как украшение карточки; стекло на карточках и формах; капс-подписи; стрелка «→» в тексте кнопок;
моноширинный шрифт для всего мелкого подряд; одна серая тень под всем подряд; сырой hex в компоненте.
