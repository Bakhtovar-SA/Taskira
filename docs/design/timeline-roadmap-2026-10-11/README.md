# Таймлайн и роудмап — исправления 11.10.2026

[Проверить на стенде](http://localhost:3000/roadmap).

На Таймлайне подпись направления остаётся видимой при горизонтальной прокрутке. Измерение области использует clientWidth, поэтому ширина раскрытого списка учитывает реальный CSS-размер при масштабе 3440. Поля «Старт (нед.)» и «Длит. (нед.)» находятся в двух колонках с подписями сверху и больше не сжимаются вложенной сеткой свойств.

В роудмапе заполненная и оставшаяся части рисуются на общей непрерывной подложке. У заполненной части прямой внутренний край; при полном выполнении остаётся округление всей полосы. Год показан для календарного года, не повторяется над каждым месяцем.

На конце полосы при наведении и фокусе есть кнопка связи. Можно перетащить её к другой полосе или нажать и выбрать проект в меню. Направление: выбранный проект ждёт исходный. На время перетаскивания показывается анимированный пунктир и контур допустимого получателя; Esc и pointercancel отменяют выбор. При reduced-motion пунктир статичный. Меню поддерживает клавиатуру; повторный выбор связанного проекта убирает связь.

Право редактирования требуется у зависимого проекта; источник должен быть виден. Самосвязь, дубли и циклы отфильтрованы в интерфейсе; существующий сервер остаётся окончательной проверкой. Ошибка API показывается уведомлением, линия не добавляется. Использованы существующие POST/DELETE dependencies, новые контракты не введены.

Если полоса целиком скрылась слева или справа, появляется кнопка с направлением и диапазоном дат. Она возвращает к полосе в текущем роудмапе и передаёт фокус её кнопке, без перехода в проект.

При ширине 1600–2559 и точном указателе локальный масштаб роудмапа 90%. Остальные разделы не менялись; на 3440 остаётся принятый общий масштаб. Высоты, положение SVG и координаты указателя проверены при масштабировании.
