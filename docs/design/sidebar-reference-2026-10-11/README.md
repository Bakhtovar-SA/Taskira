# Референс навигации · 11 октября 2026

Каждая команда представлена статичным заголовком. Под ней — заметная надпись «Проекты» без плашки и обводки, раздел открыт по умолчанию, затем реальные проекты этой команды. Название команды не кликается. Сохранены масштабы, Manrope, цвета и маркеры текущей Taskira. Линия отступа связывает список с разделом, проекты остаются отдельными переходами; меню проекта доступно при наведении.

## Отдельная реализованная правка

В карте проектов /roadmap кнопке меню зарезервировано место справа: счётчик больше не пересекается с троеточием. На телефоне счётчик тоже отодвинут от зоны кнопки. Положение счётчика при наведении не меняется. Проверенные зазоры: 18 px при 1920, 13.2 px при 3440 и 10 px при 390. [Снимок](roadmap-counter-menu-fixed.png), [геометрия](roadmap-spacing-check.json).

Правка — src/styles/roadmap.css. Production build и bundle-check прошли; существующие проверки roadmap записаны в ../audit-2026-10-09/logs/roadmap-spacing-smoke.log. API и бизнес-правила сохранены.

Проверка roadmap: 7 сценариев прошли в общем production-прогоне, геометрический сценарий прошёл отдельно после приведения устаревшего ожидания высоты toolbar (55 px) к уже согласованной плотности 52 px. См. roadmap-spacing-geometry.log. Новой правкой высота toolbar не менялась.

## Применено на стенде

По прямому поручению владельца структура из референса перенесена в действующий Sidebar.tsx. Каждая команда — статичный заголовок, под ним отдельный раздел «Проекты» без плашки и обводки. Разделы раскрыты при первом посещении; дальнейшее сворачивание каждого списка запоминается независимо. Кнопка нового проекта передаёт команду в штатный мастер. Переходы, права и меню проекта сохранены. [Текущая иерархия](implemented-hierarchy-dark-1920.png), [полный экран 3440](implemented-dark-3440.png).

Правый край панели позволяет менять ширину от 220 до 420 CSS px. Значение хранится локально, переживает перезагрузку и переход в полосу иконок. При перетаскивании за 188 CSS px панель сворачивается после отпускания; раскрытие возвращает прежнюю ширину. Двойной щелчок или Enter сбрасывают размер, стрелки меняют его на 8 px (с Shift — на 24), Home/End задают пределы. Без ручного значения сохранены прежние профили: 248 px на 1920 и 304 CSS px на 3440 с существующим общим масштабом 1.1. На узком экране остаётся drawer шириной 304 px.

При перетаскивании — одна вертикальная линия 2 px: без дополнительной рамки фокуса. После отпускания она исчезает даже при оставшемся над краем курсоре. Клавиатурный фокус обозначается одной линией 3 px. Размер обновляется через CSSOM и requestAnimationFrame без перерисовки всего приложения на каждом движении. Сохранение и ARIA-значение обновляются при завершении. [Линия во время перетаскивания](resize-line-dark.png).

Проверено на настоящем API: светлая и тёмная темы, 1920×1080 и 3440×1440; мобильное меню 390×844. В панели axe не нашёл нарушений, ошибок страницы нет. [Свидетельства](implemented-checks.json), [скрипт проверки и снимков](verify-sidebar.mjs).

Production: 8 новых сценариев панели и 2 существующих сценария shell прошли. Отдельно подтверждены 7 сценариев интеграций и повторяющихся задач. В первом общем прогоне обнаружена ошибка экспорта при объединении ленивых модулей; она исправлена статическим импортом дочерних компонентов внутри соответствующих ленивых семейств. Подтверждение — settings-chunks-confirmation.log. Сами семейства продолжают загружаться отдельно от shell, новые зависимости не добавлены. Typecheck, контраст, цвета, движение, анти-список и проверка diff прошли; layout detector вернул пустой список. Логи — в этой папке. Исходные эталоны не перезаписаны.
