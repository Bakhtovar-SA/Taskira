# UI refresh — этап 2: доска

Реализован второй пункт `design_handoff_taskira_ui_refresh/README.md`.

Карточка показывает название первым, направление отдельной строкой и метаданные
под ним: приоритет, ключ, срок и аватары 22 px. Метки скрыты на доске и сохраняются
в задаче и фильтрах. Срок различает просрочку, ближайшие три дня, более позднюю дату
и закрытую задачу. Сравнение использует локальную календарную дату. Критичный
приоритет обозначен красной полосой; у закрытых задач полоса отсутствует.
Счётчик подзадач, меню переходов, клавиша M, выбор и перенос карточек сохранены.

Колонки имеют общий размер в сетке, зазор 12 px и скругление 14 px. Четыре и пять
статусов помещаются в рабочую область на 1440 px; горизонтальная прокрутка
появляется с шестого статуса. На телефонах колонки идут вертикально. В каждой
шапке доступен «+» с созданием задачи в выбранном статусе, если позволяют права.
Закрытые задачи по умолчанию показываются за последние 14 дней; старые доступны
через «Ранее закрыто».

Общий `WorkspaceControls` поддерживает компактную строку доски: поиск 240 × 32,
«Мои», «Просрочено» с серверным счётчиком, «Без исполнителя», количество показанных
задач, группировка и «Вид». Дополнительные фильтры доступны отдельной кнопкой.
На телефонах поля и кнопки имеют высоту 44 px. Состояние поиска и фильтров
синхронизируется с URL и восстанавливается после перезагрузки. Счётчики и
пагинация используют серверные данные, включая окно закрытых задач.

Меню группировки на этом этапе содержит «Нет». Дорожки по направлению и
исполнителю оставлены на будущее, как указано в README. Список использует
прежний режим общего компонента до своего отдельного этапа.

Цвета используют семантические токены; динамический цвет направления и число
колонок задаются через CSSOM. Строки добавлены в RU и EN. HTML и inline-стили
референса в приложение не копировались.

## Проверки

- `typecheck`, `colors:check`, `contrast:check`, `motion:check`, `antilist:check` — успешно.
- Поведенческие тесты доски: 35 успешно.
- Полный `npm test -- --maxWorkers=2 --testTimeout=20000 --hookTimeout=20000` —
  90 файлов, 716 тестов успешно. Увеличение таймаутов использовано только для
  локального запуска после таймаутов при одновременной холодной загрузке браузеров;
  конфигурация unit-тестов не изменена.
- `build` и `bundle:check` — успешно; JS + CSS gzip 351.56 КиБ при существующем
  допуске роста 156 КиБ. Бюджет не изменён.
- Шесть тем: light, dark, dusk, graphite, dawn, paper; эталоны
  `e2e/__screenshots__/board-*-win32.png` сняты через `e2e/ui.visual.pw.ts` и
  просмотрены визуально, axe без serious/critical нарушений.
- Production-сборка с CSP: 31 браузерный сценарий успешно. Проверены создание
  в выбранной колонке, меню переходов с клавиатуры, состояния сроков,
  восстановление фильтров из URL, локализация, мобильные размеры и стабильность
  общих панелей доски и списка. Цвет направления применяется без нарушений CSP.

Снимки сделаны в Windows Chromium 141 / Playwright 1.56.1. На Linux сценарии
проверяют размеры и доступность, сравнение снимков потребует Linux-эталонов.
Firefox/WebKit не запускались. Проверки с моками API не заменяют интеграционный
прогон с реальным сервером.
