# Совместимость обновления UI с браузерным CI

Дата: 2026-10-05. PR #133.

Первый Linux-прогон `ui-visual` показал 34 ошибки и 189 успешных сценариев.
Остальные проверки PR, включая весь клиентский и серверный набор, прошли.

Исправлено раннее создание задачи с Главной: панель навигации уже доступна,
когда lazy-экран ещё загружается. Запрос создания теперь сохраняется до монтажа
Главной и потребляется один раз. Браузерный тест намеренно задерживает модуль,
нажимает кнопку до появления `.home-view` и проверяет выбор проекта и создание.

Прежние сценарии приведены к текущим интерфейсам: общая кнопка «Дашборд»,
активный проект и пункты навигации, поиск через палитру, фильтр задач, карточки
проектов Главной. Поиск исполнителя ограничен его всплывающим диалогом, чтобы
одноимённый аватар профиля не создавал неоднозначного селектора.

Фикстуры возвращают настоящие формы ответов назначенных задач, роадмапа и поиска.
Проверка дат отчёта сохраняет обе обязательные границы и сначала расширяет конец;
очистка по-прежнему проверяется в формах с необязательными датами. Сценарии
проверяют клавиатуру, границы экрана, разрешения, ошибки JavaScript и axe.

Typecheck и 17 unit-тестов Главной прошли. Production-сборка проходит прежний
бюджет: JS + CSS gzip 352.26 КиБ при лимите 352.49 КиБ. Эталоны DS и UI не менялись.
Полные dev- и production-прогоны запущены отдельно; результаты доступны в CI PR.
