# Информационная архитектура Taskira (ТЗ 5.6) — черновик на гейт

**Статус:** черновик, ждёт гейта владельца. После утверждения решение фиксируется в
ADR-0013 «Информационная архитектура». До этого реализация по документу не начинается
(ТЗ 5.8 и 5.9 опираются на ADR-0013).

Источник требований — `docs/design/INVENTORY.md`: карта экранов (раздел 3) и карта
настроек (раздел 4). Вайрфреймы в оттенках серого — отдельная страница-артефакт (ссылка в
PR); здесь — текст, по которому она нарисована.

Что этот документ **не** решает: цвета, шрифты, радиусы (это 5.3/5.4/ADR-0016) и новые
функции (кроме роадмапа 5.15 и мастера 5.10, которые трек уже включил).

---

## 1. Модель объектов, как её видит человек

```
Инсталляция (бренд, лицензия, пользователи)
└── Отделы
    └── Проекты  (+ «общие» проекты, видимые всем)
        ├── Представления: Доска · Список · Таймлайн · Спринты (если модуль включён)
        └── Задачи → подзадачи (2 уровня), связи, чек-лист, вложения, поля
```

Два слоя поверх:

- **Личный слой** — всё, что про «меня», поперёк проектов: Главная, Входящие, Мои
  задачи, Избранное.
- **Гостевой слой** — человек, приглашённый в отдельные задачи чужого проекта. Сейчас это
  отдельная ветка логики (`bootStatus = solo`, раздел «Мои подключения»). В новой
  структуре у гостя тот же личный слой, только без проектов (см. §6).

Словарь (одно понятие — одно слово на всём пути):

| Было в интерфейсе | Стало | Почему |
|---|---|---|
| «Список задач», `backlog` | **Список** | вкладка представления проекта рядом с «Доской» и «Таймлайном» |
| «Департаменты» (экран) | **Отделы и проекты** в настройках организации | экран управлял и отделами, и проектами, и составом |
| «Мои подключения» | **Приглашения** | человек не «подключался» — его пригласили в задачу |
| «Рабочий процесс» (экран) | **Процесс** в настройках проекта | это настройка, а не место работы |
| «Права доступа» (экран) | **Доступ** в настройках проекта | то же |
| «Документация» | **Справка** | внизу боковой панели, рядом с «?» |
| колокол | **Входящие** | колокол остаётся как быстрый вход, у ленты появляется своя страница |

## 2. Навигация

### 2.1. Боковая панель (ориентир — Linear)

```
[знак] Название инсталляции          [свернуть]
[ Поиск и команды        Ctrl K ]
[ + Новая задача              C ]

Главная
Входящие                          3
Мои задачи
Приглашения                       2   ← только если есть приглашения

Избранное                          ▾  ← только если есть избранные проекты
  [C] Корпоративные задачи

Проекты                            ▾
  Общий отдел                      ▾  ← подзаголовок, если отделов > 1
    [C] Корпоративные задачи
        Доска · Список · Таймлайн     ← раскрыт только текущий проект
    [H] Найм и адаптация
  Юридический отдел                ▸

Организация
  Роадмап                             ← 5.15
  Отчёты

────────────────
Справка        ?
Настройки
[аватар] Имя · роль
```

- Панель сворачивается в полосу иконок (состояние — в `localStorage`, как тема).
- Текущий проект раскрыт и показывает свои представления; остальные — одной строкой.
- «Настройки» внизу ведут в тот раздел настроек, который уместен: из проекта —
  настройки проекта; иначе — личные. Внутри — переключатель трёх разделов (§3).
- Счётчик у «Входящих» — непрочитанные; у «Приглашений» — число задач.
- Прогресс проекта (полоса «открытых задач» внизу сейчас) переезжает в шапку проекта и
  на роадмап: в боковой панели ему не место.

### 2.2. Верхняя панель страницы проекта

```
[C] Корпоративные задачи ★   | Доска | Список | Таймлайн | Спринты |    [Фильтр] [Вид] [⋯] [+ Задача]
```

- Слева — значок, название проекта, звезда избранного; клик по названию — переключатель
  проектов (как сейчас крошка).
- Вкладки представлений. «Спринты» — только при включённом модуле.
- «Фильтр» — общие фильтры представления (сейчас чипы доски и фильтры списка — два
  разных набора, станет один).
- «Вид» — параметры отображения (сейчас их нет; группировка/сортировка/поля карточки —
  это 5.12, здесь только место под кнопку).
- «⋯» — «Настройки проекта», «Скопировать ссылку», «Импорт из Trello».
- Поле поиска из шапки уходит в палитру Ctrl K (там уже есть поиск по задачам всех
  проектов и по подстроке в текущем). «/» открывает палитру сразу в режиме задач.
- Колокол остаётся в шапке как быстрый просмотр входящих.

### 2.3. Страницы вне проекта

Главная, Входящие, Мои задачи, Приглашения, Роадмап, Отчёты, Настройки — у них своя
шапка: заголовок страницы и её действия, без вкладок проекта.

## 3. Карта настроек — ровно три дома

У каждой настройки один дом; inline-ярлыки в других местах **ведут** туда, форму не
дублируют. Графа «сейчас» — из карты 4 `INVENTORY.md`.

### 3.1. Личные (`/settings/…`, любой пользователь)

| Раздел | Что внутри | Сейчас |
|---|---|---|
| Профиль | имя, должность, телефон — только просмотр (задаются админом/LDAP); аватар | аватар — в карточке пользователя; поля не видны нигде |
| Уведомления | почта: «сразу / дайджест»; «подписывать на мои задачи» | меню пользователя в шапке проекта; на Главной и у гостя блока нет |
| Внешний вид | тема, атмосфера, (плотность, движение — когда появятся) | меню пользователя → «Оформление» |
| Язык | русский / English | там же |

Меню аватара становится коротким: карточка профиля, «Настройки», «Выйти». Быстрый
переключатель темы остаётся в палитре Ctrl K.

### 3.2. Проект (`/p/:key/settings/…`, по правам проекта)

| Раздел | Что внутри | Право | Сейчас |
|---|---|---|---|
| Общее | название, ключ (только просмотр), описание, отдел, «общий проект», значок и цвет | admin | название и «общий» — в «Департаментах»; описание и отдел — нигде (только API) |
| Процесс | карта статусов, переходы, сброс схемы (с подтверждением) | `editWorkflow` | экран «Рабочий процесс» |
| Поля | кастомные поля: создание, переименование, удаление | `editWorkflow` | «Рабочий процесс»; переименование — только API |
| Шаблоны задач | создание, редактирование, удаление | `editWorkflow` | «Рабочий процесс»; редактирование — только API |
| Доступ | участники и роли, матрица прав (справочно) | `manageAccess` | **в двух местах**: «Права доступа» и «Департаменты → Состав» |
| Модули | спринты вкл/выкл | admin | чекбокс в «Департаментах» |
| Архив и удаление | архивные задачи проекта (`?archived=1`), удаление проекта | admin | архив — только по прямой ссылке; удаление — корзина в «Департаментах» |

### 3.3. Организация (`/admin/…`, глобальный admin)

| Раздел | Что внутри | Сейчас |
|---|---|---|
| Пользователи | список, создание (local), глобальная роль, деактивация | нигде (только API) |
| Отделы и проекты | отделы, их состав, проекты отдела (создать; открыть настройки проекта) | экран «Департаменты» |
| LDAP | статус подключения, «Проверить связь», «Пересинхронизировать», LDAP-группы отделов | ресинк — в «Департаментах»; проверка связи — только API |
| Бренд | название инсталляции, знак, оттенок акцента (5.14) | нет |
| Лицензия | статус, места, срок (из `getLicenseStatus`) | нигде (только CLI) |
| Экспорт | полный экспорт инсталляции, экспорт аудита | «Экспорт данных» в «Департаментах»; аудит — только API |
| Аудит | просмотр журнала (если появится маршрут), экспорт, срок хранения — справочно | нигде |
| Обслуживание | статус фоновых задач, dry-run и запуск (MAINT-01) | нигде (только API) |
| Состояние системы | предупреждения из `/api/health` (например, нет поискового индекса) | нигде |

Только env (SMTP, `ARCHIVE_AFTER_DAYS`, интервалы) — показываются **справочно**, без
редактирования: ТЗ 5.9 запрещает добавлять новые настройки.

## 4. Просмотр задачи

**Рекомендация (как в треке):** боковая панель из Доски и Списка + полная страница по
адресу. Модалка уходит.

- Клик по карточке или строке → **панель справа** (уже сделано в этом PR), доска остаётся
  видна. Адрес — `/p/KEY/board?issue=CORP-12` (адресуемо, «назад» закрывает панель).
- Кнопка «Открыть полностью» в панели и любая пришедшая ссылка `/p/KEY/issue/CORP-12` →
  **полная страница** задачи: две колонки, лента комментариев и истории.
- `J` / `K` — следующая / предыдущая задача текущего представления без закрытия панели.
- Из Входящих, Моих задач и поиска задача открывается полной страницей (контекста доски
  там нет).

## 5. Маршруты и редиректы

Ссылки уже рассылаются людьми (ТЗ 3.1) — каждая старая должна открывать правильное место.

| Новый путь | Экран |
|---|---|
| `/` | Главная |
| `/inbox` | Входящие |
| `/my-issues` | Мои задачи |
| `/shared` | Приглашения (гость и участник) |
| `/roadmap` | Роадмап проектов (5.15) |
| `/reports` | Отчёты (без изменений) |
| `/help` | Справка |
| `/settings/{profile,notifications,appearance,language}` | Личные настройки |
| `/p/:key` | последнее открытое представление проекта (по умолчанию Доска) |
| `/p/:key/{board,list,timeline,sprints}` | представления |
| `/p/:key/issue/:issueKey` | полная страница задачи |
| `/p/:key/settings/{general,workflow,fields,templates,access,modules,archive}` | настройки проекта |
| `/admin/{users,departments,ldap,brand,license,export,audit,maintenance,health}` | настройки организации |

| Старый путь | Редирект |
|---|---|
| `/p/:key/backlog` (+ query фильтров) | `/p/:key/list` (query сохраняется) |
| `/p/:key/workflow` | `/p/:key/settings/workflow` |
| `/p/:key/access` | `/p/:key/settings/access` |
| `/p/:key/admin` | `/admin/departments` (не-админу — 403 с объяснением, не пустой экран) |
| `/p/:key/docs` | `/help` |
| `/p/:key/collaborating` | `/shared` |
| `/p/:key/sprints` при выключенном модуле | `/p/:key/board` + тост «Модуль спринтов выключен» (сейчас — экран-отказ) |
| `/p/:key/issue/:issueKey` | без изменений; раньше — доска + модалка, теперь — полная страница |
| `?q=…&scope=all` | открывает палитру с этим запросом |

## 6. Гостевой путь

Гость — приглашён к задачам, но не участник ни одного проекта.

- Входит на `/shared` («Приглашения»): список задач, куда его пригласили, сгруппированный
  по проектам, с пояснением одной строкой «Вас пригласили в эти задачи. Проекты целиком
  вам не видны».
- Боковая панель: Главная, Входящие, Приглашения, внизу Справка и Настройки. Раздела
  «Проекты» и «Организация» нет.
- Задача открывается полной страницей; поля, которые гость не может менять, — только
  чтение с подсказкой «Менять может участник проекта».
- Личные настройки (уведомления, тема, язык) доступны так же, как всем — сейчас у гостя
  их нет вовсе.
- Участник с приглашениями видит «Приглашения» в личном слое со счётчиком.

## 7. Горячие клавиши

| Клавиши | Действие | Сейчас |
|---|---|---|
| `Ctrl K` / `⌘K` | палитра команд | есть |
| `/` | палитра в режиме поиска задач | фокус поля поиска в шапке |
| `C` | новая задача | есть |
| `?` | справка по клавишам | есть |
| `G` затем `H` / `I` / `M` / `R` / `P` | Главная / Входящие / Мои задачи / Отчёты / Роадмап | нет |
| `1` / `2` / `3` / `4` | Доска / Список / Таймлайн / Спринты текущего проекта | `1`–`9` на все разделы, включая настройки |
| `G` затем `S` | настройки текущего проекта | нет |
| `J` / `K` | следующая / предыдущая задача | нет |
| `M` | сменить статус задачи в фокусе | есть на доске |
| `Esc` | закрыть панель / диалог | есть |

`4`–`9` больше не открывают экраны настроек: это решает находки 2.2 и 2.3 из
INVENTORY (клавиша открывает скрытый или запрещённый экран).

## 8. «Разбросано»: было → стало

| Жалоба / находка INVENTORY | Было | Стало |
|---|---|---|
| Участники проекта в двух местах | «Права доступа» и «Департаменты → Состав» | один дом: Настройки проекта → Доступ; в «Отделах и проектах» — ссылка «Участники» туда |
| Настройки проекта размазаны | название и «общий» — «Департаменты»; процесс, поля, шаблоны — «Рабочий процесс»; спринты — чекбокс в «Департаментах» | Настройки проекта: Общее, Процесс, Поля, Шаблоны, Модули |
| Экспорт в трёх местах | «Департаменты», «Отчёты», «Список» (импорт) | полный экспорт и аудит — Организация → Экспорт; CSV отчёта остаётся действием отчёта (это выгрузка результата, не настройка); импорт — «⋯» проекта |
| Личное — в меню аватара, и не везде | уведомления только в шапке проекта; на Главной и у гостя нет | Личные настройки — одна страница, доступна всем |
| Серверное без интерфейса | лицензия, обслуживание, предупреждения здоровья, аудит, пользователи, LDAP-проверка | Организация: соответствующие разделы (реализация — 5.9) |
| Экраны-отказы по клавишам 7 и 9 | клавиша открывает скрытый экран | клавиши только на представления проекта |
| Документация среди рабочих разделов | пункт «Документация» между «Департаментами» и «Моими подключениями» | Справка внизу панели и `?` |
| Отчёты «привязаны» к проекту в панели | пункт в группе проекта, хотя экран без проекта | Организация → Отчёты |

## 9. Решения на гейт

1. Состав боковой панели (§2.1): личный слой сверху, проекты по отделам, «Организация»,
   настройки внизу.
2. Три дома настроек и таблицы §3 (в т. ч. «Участники» — только в Доступе проекта).
3. Просмотр задачи: панель из Доски/Списка + полная страница по ссылке; модалка уходит.
4. Новые адреса и редиректы §5; `/` — Главная всегда (сейчас при одном проекте `/`
   открывает доску; предлагаю: при одном проекте после входа — сразу проект, но
   Главная доступна из панели).
5. Горячие клавиши §7: `1`–`4` только на представления, навигация по `G` + буква.
