# Ручная проверка трека 5 (ТЗ 5.10–5.12…)

Что проверить на своём ПК после `git pull` (ветка `claude/peaceful-bell-nw8dby`). Перед проверкой:
`npm ci` в корне и в `server/`, затем `npm run dev` и `cd server && npm run dev` — миграции применятся сами.
Автотесты всё это уже покрывают; здесь — то, что стоит увидеть глазами и прощёлкать руками.
