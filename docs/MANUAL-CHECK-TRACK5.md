# Ручная проверка трека 5 (ТЗ 5.10–5.12…)

Что проверить на своём ПК после `git pull` (ветка `claude/peaceful-bell-nw8dby`). Перед проверкой:
`npm ci` в корне и в `server/`, затем `npm run dev` и `cd server && npm run dev` — миграции применятся сами.
Автотесты всё это уже покрывают; здесь — то, что стоит увидеть глазами и прощёлкать руками.

## 5.10 — шаблоны проектов, мастер, внешний вид

- [ ] «+» у «Проектов» в сайдбаре → мастер: выбрать «Согласование документов», название, ключ подставился.
- [ ] Шаг 2: иконка и цвет; шаблон сам предлагает иконку. Шаг 4: выбрать фон — он сразу виден за окном;
      закрыть мастер крестиком — фон вернулся прежний.
- [ ] Создать проект → он открылся, в сайдбаре с иконкой и цветом; фон проекта включился.
- [ ] Настройки проекта → Процесс: схема из 7 статусов читается, стрелки не перепутаны.
- [ ] Настройки проекта → Общее → «Внешний вид»: сменить иконку/цвет/фон — меняется сразу везде.
- [ ] «Сохранить как шаблон» → Организация → «Шаблоны проектов»: шаблон появился; новый проект из него.
- [ ] Личный фон (Настройки → Внешний вид) в проекте со своим фоном — подпись, что показывается фон проекта.

## 5.11 — онбординг

- [ ] Первый вход администратора на чистой БД (или `UPDATE instance SET setup_completed_at = NULL`) —
      открывается «Начальная настройка». Пройти шаги, «Завершить» — больше сама не открывается.
- [ ] Создать демо-проект → доска с заявками, метка «демо» в сайдбаре. «Удалить демо» — пропал.
- [ ] Обычный пользователь: на главной «Начало работы». Открыть свою задачу, сменить статус, написать
      комментарий, сохранить уведомления, сменить тему — шаги отмечаются. Скрыть — не возвращается,
      в том числе в другом браузере.
- [ ] Подсказки (список → вьюхи, доска → перенос, панель задачи → J/K, «Мои задачи» → Ctrl K): закрыть
      крестиком — больше не появляются.
- [ ] Гость (приглашён только в задачу, без проектов): слева блок «Вы — гость».
- [ ] Пустые состояния: пустой проект (доска), пустой список, таймлайн без направлений, входящие.
- [ ] **Главная проверка ТЗ 5.11**: человек со стороны от чистой установки до рабочего проекта — меньше 5 минут
      без документации.

## 5.12 a — вход, ошибки, 404, офлайн

- [ ] Вход: неверный пароль — понятная ошибка; глазик показывает пароль; при включённом Caps Lock — подсказка.
- [ ] Остановить сервер API и обновить страницу — экран «Не удалось загрузить Taskira» (не форма входа!),
      «Повторить» после запуска сервера — всё загрузилось, заново входить не пришлось.
- [ ] Выключить сеть (или DevTools → Offline) посреди работы — жёлтая полоса «Нет связи»; включить — пропала.
- [ ] Открыть ссылку на несуществующий проект/задачу (`/p/NOPE/board`, `/p/CORP/issue/CORP-99999`) —
      «Здесь ничего нет» с адресом; «На главную» и «Назад» работают.
- [ ] Узкий экран (телефон, ~390 px): вход и эти экраны не разваливаются.

## 5.12 b — Главная

- [ ] «Все мои» разбиты по срочности: Просрочено / Сегодня / На этой неделе / Позже / Без срока. Цифры сверху
      фильтруют список; при фильтре или поиске — плоский список.
- [ ] Упомяните себя (@) в комментарии от другого пользователя — на Главной появился блок «Упоминания».
- [ ] Откройте пару задач — на Главной блок «Недавно открытые».
- [ ] Телефон (~390 px): шапка Главной не вылезает за экран.
- [ ] English: Настройки → Язык → English — всё переключилось без мигания; обновить страницу — сразу на английском.

## 5.12 c — Доска

- [ ] Карточка: ключ, заголовок (не больше двух строк), внизу направление/метки/срок и исполнители справа.
      Приоритета, типа и подзадач на карточке больше нет — они в самой задаче. **Посмотрите, устраивает ли так.**
- [ ] Срок подсвечен красным только если просрочен; «скоро» больше не выделяется.
- [ ] Колонка — одна поверхность, заголовок с числом не уезжает при прокрутке карточек.
- [ ] Ширина колонок: на широком мониторе растягиваются до 360 px и стоят по центру; на узком — прокрутка вбок
      от левого края, ничего не обрезается слева.
- [ ] Перетаскивание, клавиша M, «Ранее закрыто», быстрое создание «+», фильтры — работают как раньше.

## 5.12 d — Просмотр задачи

- [ ] Под описанием — одна лента: «Всё» (комментарии и события вперемешку, новые сверху), «Комментарии», «История».
- [ ] Описание: кликнуть, поправить, кликнуть мимо — сохранилось без кнопки. Esc — отмена, задача не закрылась.
- [ ] J/K в панели листают задачи; на полной странице кнопок «вверх/вниз» нет.

## 5.12 e — Список задач

- [ ] Список — таблица: заголовки «Ключ», «Приоритет», «Срок», «Обновлено» сортируют по клику (второй клик — обратный
      порядок); заголовок прилипает сверху при прокрутке длинного списка.
- [ ] «Колонки» в панели: включить «Тип» и «Обновлено», выключить «Метки» — таблица перестроилась; обновить
      страницу — выбор сохранился.
- [ ] «Выделить» → галочка в заголовке выделяет все строки, повторный клик снимает; массовые действия как раньше.
- [ ] Телефон (~390 px): видны название (ключ мелко над ним), статус и исполнители; ничего не обрезано справа.

## 5.12 f — Таймлайн

- [ ] Переключатель «Недели / Месяцы / Кварталы»: полосы направлений сжимаются, шапка показывает месяцы и годы
      или кварталы; выбор сохраняется после обновления страницы.
- [ ] Линия и плашка «сегодня» на месте при любом масштабе; «Сегодня» прокручивает к началу.
- [ ] Раскрыть направление — список задач не уезжает при прокрутке вбок; клик по полосе открывает направление.
- [ ] Телефон (~390 px): переключатель масштаба переносится под заголовок, шкала прокручивается пальцем.

## 5.12 g — Входящие

- [ ] От другого пользователя дважды прокомментируйте и смените статус вашей задачи — во «Входящих» одна строка
      по задаче с пометкой «ещё N»; клик — открывает задачу и отмечает прочитанными все её события; крестик —
      убирает все её события.
