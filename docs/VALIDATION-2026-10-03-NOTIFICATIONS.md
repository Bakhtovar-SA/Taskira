## Ограничения и выпуск

Реальный корпоративный Outlook и корпоративный SMTP здесь недоступны; их визуальный рендер/доставляемость не подтверждены. Outlook-разметка использует таблицы, inline-стили, системные шрифты и условный MSO-контейнер.

Рабочая база не изменялась. Миграции применялись только к выделенной `taskira_test`. Перед установкой требуется проверенная резервная копия рабочей БД. Новые напоминания включены по умолчанию; старые настройки подразумевают интервалы `[1,0]`. Для остановки создания — `DUE_REMINDER_ENABLED=false`. Уведомления дедуплицируются транзакционно; SMTP сохраняет существующую модель повторных попыток (см. NOTIFICATIONS_SETUP, §5).

Окончательное объединение PR — после отдельного разрешения владельца. Отчёт описывает локальные проверки; результаты GitHub CI следует смотреть в самом PR.
