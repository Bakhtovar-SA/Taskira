# Ручная проверка — часть F

Перед проверкой: `git pull`, `npm ci` в корне и в `server/`, запустить оба `npm run dev`. Две новые миграции
(`20260930T0500_epic_child_counts.sql`, `20260930T0501_index_issues_epics.sql`) применятся сами при старте сервера.

- [ ] **Широкий монитор.** Доска: колонки начинаются сразу под заголовком «Доска» и фильтрами, а не посередине
      экрана; на мониторе 2560+ колонки шире, чем раньше. Список задач: таблица тоже начинается от левого края.
      На обычном экране (1440–1920) доска выглядит как раньше, на телефоне колонки листаются по одной.
- [ ] **Ссылка на приглашённую задачу посреди работы.** Под человеком, приглашённым к задаче в чужом проекте (не
      участником проекта), открыть свой проект, затем вставить в адресную строку ссылку на ту задачу
      (`/p/КЛЮЧ/issue/КЛЮЧ-N`). Открываются «Мои подключения», и нужная карточка уже выбрана.
- [ ] **Направления.** В задаче указать направление, сменить его, снять; перевести задачу направления в «Готово» и
      обратно. На таймлайне и в фильтре «Направление» у списка счётчики «N/M задач» меняются сразу и верно.
- [ ] **Консоль браузера** в dev-режиме: на доске, в списке, настройках нет красных предупреждений React о `key`.
