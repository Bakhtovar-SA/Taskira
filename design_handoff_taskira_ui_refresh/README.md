# Handoff: Taskira — UI refresh (shell, board, issue, list, home, roadmap, reports)

## Как использовать (промпт для агента)

> Ты работаешь в репозитории `Bakhtovar-SA/Taskira`. В папке `design_handoff_taskira_ui_refresh/` лежат HTML-макеты и этот README.
> Реализуй изменения из раздела «Экраны» в существующем коде (`src/`), строго по правилам из `docs/design/DESIGN.md`, `CLAUDE.md` и ADR-0027.
> Не копируй HTML и inline-стили — переложи на токены `src/styles/tokens.css`, Tailwind-классы и компоненты `src/ds/*`.
> Делай по одному экрану на PR в порядке из раздела «Порядок работ». После каждого PR: `npm run typecheck`, `npm test`, `npm run colors:check`, `npm run contrast:check`, `npm run motion:check`, `npm run antilist:check`, `npm run build`, `npm run bundle:check`, обновить скриншоты `e2e/ui.visual.pw.ts`.
> Все строки интерфейса — через i18n (`src/i18n`), RU и EN.

## Overview
Ревью текущего интерфейса (main @ 34a0943, скриншоты аудита 2026-10-03) и предложения «было / стало» для 6 экранов. Цель — убрать дубли в оболочке (поиск ×3, «Создать» ×2, профиль ×2), вернуть высоту рабочей области, показать все свойства задачи, сделать доску и список плотнее, привести Главную/Отчёты/Роадмап к общей оболочке.

## About the Design Files
Файлы в этой папке — **дизайн-референсы в HTML**, а не продакшн-код. Задача — воссоздать их в существующем стеке Taskira (React 19 + TypeScript + Tailwind 4, собственная DS `src/ds/`, иконки `src/icons.tsx`) по его паттернам. Inline-стили в макетах использовались только для прототипа; в продукте действует CSP без inline-стилей (ADR-0010) и запрет сырых цветов вне `tokens.css` (`colors:check`).

## Fidelity
**High-fidelity.** Цвета, шрифт, радиусы и отступы взяты из `src/styles/tokens.css` (светлая тема). Тёмная тема и курируемые скины должны работать автоматически через семантические токены — проверить визуально.

## Порядок работ
1. Оболочка: шапка проекта в одну строку + боковая панель.
2. Доска (карточка и колонки).
3. Карточка задачи (панель).
4. Список (группировка).
5. Главная в общей оболочке.
6. Роадмап.
7. Отчёты и дашборды + баги.

## Доступность
- Текст не меньше 12px (сейчас 11px у плашек статуса, 8–9px у инициалов).
- Аватары от 22px.
- Срок дублируется текстом («просрочено 2 дня»), не только цветом.
- Новые экраны прогнать через axe в `e2e/design-audit.pw.ts`.

## State
- Шапка: активное представление (URL), избранное проекта.
- Доска/Список: фильтры и группировка — в URL (как сейчас, ADR-0027 п.5), `group` = none | status | epic | assignee.
- Задача: следующий переход = `transitions.filter(from === current).sort(by category order)[0]` с учётом прав (`can()`).
